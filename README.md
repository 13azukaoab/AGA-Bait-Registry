## การแบ่ง Tier ลูกค้า

จัด Tier จาก **มูลค่าต่อปี** ไม่ใช่มูลค่าสัญญาเต็ม:

```
มูลค่าต่อปี = มูลค่าสัญญา ÷ จำนวนปีสัญญา
```

| Tier | มูลค่าต่อปี (บาท) |
|---|---|
| **S** | < 30,000 |
| **M** | 30,000 – 49,999.99 |
| **L** | 50,000 – 99,999.99 |
| **XL** | ≥ 100,000 |

- รหัสเต็ม = Tier + จำนวนปีสัญญา (1 หรือ 3) → `s1/m1/l1/xl1` (1 ปี) · `s3/m3/l3/xl3` (3 ปี)
- ตัวอย่าง:

| มูลค่าสัญญา | ปี | ต่อปี | Tier |
|---|:--:|---|:--:|
| 50,000 | 3 | 16,667 | **S3** |
| 150,000 | 1 | 150,000 | **XL1** |
| 150,000 | 3 | 50,000 | **L3** |
| 29,999.50 | 1 | 29,999.50 | **S1** |

> ⚠️ เกณฑ์ Tier เก็บในตาราง `tier_rules` (Host แก้ได้) — **ห้าม hardcode ในโค้ด**
> ป้ายเดิมใน Excel ที่เขียน `M3 (>30-49.9K)` สะกดช่วงผิด ห้ามคัดลอก

## บทบาทผู้ใช้ (role)
| Role | คือใคร | แก้อะไรได้ |
|---|---|---|
| `host` | ส่วนกลาง Bait / QCS | ทุกอย่าง + จัดการ user / Tier / ปิดเดือน |
| `admin` | แอดมินระบบเหยื่อ | ลูกค้า + สัญญา + สถานี |
| `recorder` | หัวหน้างาน | ผลบริการ (การเข้าบริการ + ตรวจสถานี) |
| `viewer` | ผู้บริหาร / ฝ่ายขาย | ดูเฉพาะตัวเลขสรุป (PDPA) |
