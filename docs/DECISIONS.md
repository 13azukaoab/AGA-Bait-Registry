# DECISIONS.md — เรื่องที่ตัดสินแล้ว (AGA Bait Registry)

> จัดทำ 10 พ.ย. 2026 (งาน B2 ใน `docs/แผนงานแก้ไข.md`) · **รวมทุกเรื่องที่เจ้าของตัดสินไปแล้ว ไว้ที่เดียว** เพื่อให้ทีม (นัท / Jane / Toon) และ session ใหม่เปิดไฟล์เดียวแล้วรู้ว่า "อะไรตกลงกันแล้ว ห้ามรื้อซ้ำ" และ "อะไรยังค้าง"
>
> **ไฟล์นี้ไม่ใช่ข้อกำหนด** — ข้อกำหนดตัวจริงคือ `SPEC.md` ไฟล์นี้เป็นสมุดบันทึกว่าใครตัดสินอะไรเมื่อไหร่ และไปอยู่ที่ไหนใน SPEC
> ถ้าไฟล์นี้ขัดกับ `SPEC.md` → **ยึด `SPEC.md`** แล้วแจ้งเจ้าของให้แก้ไฟล์นี้ตาม
>
> อ่านคู่กับ: `SPEC.md` (ข้อกำหนด) · `task.md` (ความคืบหน้า + changelog) · `docs/แผนงานแก้ไข.md` (แผนรายข้อ A1–E1, คำถาม D1–D13) · `docs/แบ่งงาน-5-หมวด.md` (แบ่งงานเป็น session)

## วิธีใช้ไฟล์นี้

| สัญลักษณ์ | ความหมาย |
|---|---|
| ✅ | ตัดสินแล้ว **และ** ลงใน `SPEC.md` เรียบร้อย |
| 🔧 | ตัดสินแล้ว ลง SPEC แล้ว แต่ **โค้ด/ฐานข้อมูลยังไม่ทำตาม** (ดูหัวข้อ "ตัดสินแล้วแต่ยังไม่ได้ทำ") |
| ⏳ | **ยังไม่ตัดสิน** — ห้ามเดา ต้องถามเจ้าของก่อน (ดูหัวข้อ "ยังค้างรอเจ้าของ") |

**กฎเวลาจะรื้อข้อที่ตัดสินแล้ว:** ทักท้วงได้ถ้าเจอจุดอ่อน แต่ต้องเสนอเป็นทางเลือกให้เจ้าของตัดสินใหม่ **ห้ามเปลี่ยนเอง** แล้วถ้าเจ้าของเปลี่ยนใจ ให้แก้ 3 ที่: `SPEC.md` §17 · ไฟล์นี้ · `task.md`
