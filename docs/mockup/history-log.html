ประวัติย้อนหลัง

ดูว่า ใคร แก้ / ลบ / เพิ่ม อะไร เมื่อไหร่ — มาจากบันทึกการแก้ไขของระบบ (audit_log) · เฉพาะ host (PM/OM) · ข้อมูลในหน้านี้เป็นตัวอย่างสมมติ

🔒

หน้านี้สำหรับ host เท่านั้น

บทบาทนี้ไม่มีสิทธิ์ดูประวัติการแก้ไขทั้งระบบ — สิทธิ์บังคับที่ฐานข้อมูล (RLS ของ audit_log อ่านได้เฉพาะ host) ไม่ใช่แค่ซ่อนปุ่ม

ⓘ
"วันที่แก้" ไม่เท่ากับ "เดือนของข้อมูล" วันที่แก้ = วันที่มีคนกดบันทึก (คอลัมน์ "เวลา") · เดือนของข้อมูล = เดือนบริการที่ข้อมูลนั้นสังกัด (ใต้คอลัมน์ "ข้อมูล") ตัวอย่าง: แก้เมื่อ 9 พ.ย. แต่เป็นผลบริการของเดือน ต.ค. ที่ปิดแล้ว → ขึ้นป้าย 🔒แก้หลังปิดเดือน ระบบไม่ล็อกข้อมูล แต่ ค่าที่ส่ง Dashboard ยังเป็นค่าเดิม จนกว่าจะสั่ง "คำนวณ snapshot ใหม่" ที่หน้า ส่งข้อมูล และสรุปงานประจำเดือน

รายการแสดงทีละ 25 (ของจริง 50) · ค่าเริ่มต้นไม่รวมการกรอกผลบริการปกติ เพราะหัวหน้างานกรอกวันละหลายสิบถึงร้อยราย — ดูได้ที่ปุ่ม "รวมการกรอกปกติ" (รวมเป็น 1 แถวต่อคนต่อวัน)
