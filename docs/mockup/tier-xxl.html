1) ป้ายทั้ง 10 แบบเรียงกัน

8 แบบเดิมไม่เปลี่ยน · XXL1 = 1 ปี (พื้นอ่อน ตัว ink) · XXL3 = 3 ปี (พื้นทองเต็ม) · ตัวเลขใต้ป้ายคืออัตราส่วนความคมชัดของตัวหนังสือ เทียบพื้นป้าย (คำนวณจริงจากสีที่แสดงอยู่ตอนนี้ ต้อง ≥ 4.5)

2) ชิปในตารางสัญญา

ผสม S1…XL3 และ XXL1/XXL3 หลายแถว — ลองเลื่อนดูว่าป้าย XXL หลายแถวขยับพร้อมกันรบกวนสายตาหรือไม่ (ข้อมูลสมมติ)

เลขสัญญาลูกค้า (สมมติ)สาขามูลค่าต่อปี (บาท)Tier

3) แถบสี Tier ในหน้าตั้งค่า (5 ช่อง)

ตำแหน่งจริง: หน้าตั้งค่า > เกณฑ์ Tier · ช่วงมูลค่า XXL ยังไม่กำหนด (ตัวเลขช่อง S–XL ด้านล่างเป็นตัวอย่างสมมติ)

S< 30,000
M30,000 – 69,999
L70,000 – 149,999
XL150,000 – (?)
XXLยังไม่กำหนดเกณฑ์

4) Legend (คำอธิบายสี)

ป้ายที่ไม่ระบุปี ใช้สีกลุ่มของ tier นั้น

S M L XL XXL อ่อน = 1 ปี · เข้ม = 3 ปี

หรือแบบมีป้ายจริง:

XXL1 1 ปี XXL3 3 ปี

5) ตัวกรอง Tier (แบบหน้า /summary)

กดเลือก/ไม่เลือกได้ — จุดกดสูง 44px

6) animation 3 แบบ — ข้อดี/ข้อเสีย

แต่ละการ์ดเล่นแบบของตัวเองเสมอ (ไม่ขึ้นกับปุ่มด้านบน) · ยกเว้นเปิด "จำลอง reduced motion" จะหยุดหมด

ก) Shimmer — ประกายวิ่งผ่าน แนะนำ

XXL1XXL3
  • ดูหรู เหมือนป้ายทอง ไม่ฉูดฉาด
  • มีช่วงพัก (วิ่ง ~1.4 วิ แล้วนิ่ง ~2.2 วิ) ไม่รบกวนตอนอ่านตัวหนังสือ
  • เบา ใช้ CSS ล้วน
  • ตารางยาว ป้ายหลายแถววิ่งพร้อมกัน ตาจะไปจับที่ประกาย

ข้อสังเกตสายตา

  • แนะนำให้ "เล่นเฉพาะตอน hover แถว" ในตาราง และเล่นอัตโนมัติเฉพาะ legend / หน้าตั้งค่า

ข) Glow pulse — เรืองแสงเต้นเบาๆ

XXL1XXL3
  • เห็น "นีออน" ชัดที่สุดตามโจทย์
  • เปลี่ยนค่าเรียบๆ ไม่มีจังหวะกะพริบ (รอบละ ~5 วิ)
  • แสงเรืองของแถวติดกันจะเบลอซ้อนกัน ดูรก
  • บนธีมสว่างแสงทองจางกว่าธีมมืด
  • แสงทำให้ป้ายดูใหญ่/เด่นกว่าป้ายอื่นมาก

ข้อสังเกตสายตา

  • ป้ายหลายแถวเต้นพร้อมกันเห็นเป็นจังหวะเดียวกันทั้งตาราง — ควรใช้เฉพาะจุดเด่น เช่น ชิปตัวกรอง/หัวหน้ารายละเอียดลูกค้า

ค) ขอบไฟวิ่ง — กรอบไล่สีหมุนรอบป้าย

XXL1XXL3
  • ตัวอักษรไม่ถูกบัง (animation อยู่ที่ขอบ)
  • ดูเป็น "ระดับสูงสุด" ชัดเจน
  • ป้ายเล็ก ขอบ 1.5px ทำให้ป้ายสูง/กว้างขึ้นเล็กน้อย
  • ใช้ @property — เบราว์เซอร์เก่ามากจะไม่หมุน (ยังเห็นขอบนิ่ง)
  • ขอบหมุนต่อเนื่องดึงสายตาที่สุดในสามแบบ

ข้อสังเกตสายตา

  • ไม่ควรเปิดตลอดในตารางยาว · เหมาะกับหน้ารายละเอียดสัญญาที่มีป้ายเดียว

ง) ไม่มี animation (ทางเลือกปลอดภัย)

XXL1XXL3
  • ไม่รบกวนสายตา ไม่มีปัญหาแบตมือถือ/ประสิทธิภาพ
  • ยังต่างจาก XL ชัด (พื้นทอง + ขอบ + แสงนิ่ง)
  • ขาดความ "นีออนมีชีวิต" ที่ขอไว้

ผู้ใช้ที่เปิด reduced motion จะเห็นแบบนี้เสมอ ไม่ว่าเลือกแบบใด

7) ตารางอัตราส่วน contrast ทุกชุด (คำนวณสดจากสีจริง)

เกณฑ์ตัวหนังสือ ≥ 4.5:1 · คอลัมน์ "พื้นป้ายเทียบพื้นหน้า" ให้ดูประกอบ — ทองสว่างบนพื้นขาวไม่ถึง 3:1 จึงต้องพึ่งขอบ/แสง และ ตัวอักษรบอกชื่อ "XXL" เสมอ ห้ามพึ่งสีอย่างเดียว

โทน / ธีมป้ายตัวหนังสือพื้นป้ายตัวหนังสือ : พื้นผลพื้นป้าย : พื้นหน้า

หมายเหตุ: XXL3 ใช้ตัวหนังสือเข้ม (ไม่ใช่ตัวขาว เหมือน 3 ปีของ tier อื่นในธีมสว่าง) เพราะตัวขาวบนทองได้เพียง ~1.9:1 · ในธีมมืด tier อื่นก็ใช้ตัวเข้ม #0b1420 อยู่แล้ว จึงเข้ากัน

หมายเหตุและคำถามถึงเจ้าของ

ยังไม่ได้ตัดสินใจ / ต้องทำจริงภายหลัง
  • เกณฑ์มูลค่าของ XXL ยังไม่กำหนด (ตอนนี้ XL คือ "ตั้งแต่ 150,000 ขึ้นไป" ไม่มีเพดาน)
  • ของจริงต้องแก้ lib/rules (tierOf / ชนิด Tier), ตาราง tier_rules ในฐานข้อมูล (migration ใหม่ ห้ามแก้ไฟล์เก่า), หน้าตั้งค่า, ตัวกรอง /summary และ unit test
  • Dashboard ปลายทาง: รูปแบบ dashboard_data.json ห้ามเปลี่ยน (16 ฟิลด์ต่อแถว) — XXL จะไปลงช่องไหน (รวมกับ XL หรือแยก) ต้องตัดสินก่อน
  • ข้อมูลในตารางหน้านี้ทั้งหมดเป็นข้อมูลสมมติ
