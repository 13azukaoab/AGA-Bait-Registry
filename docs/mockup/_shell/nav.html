งานประจำวัน
สถานะทะเบียนบริการ ลงข้อมูลทำบริการประจำเดือน กล่อง AG นอกรอบประจำเดือน ลูกค้ารอเก็บสถานี
ทะเบียนและสรุป
ทะเบียนลูกค้า/สัญญา เปิดงานเข้าทะเบียนบริการ สรุปงานบริการรายเดือน Dashboard สรุปมูลค่าทั้งหมด
ดูแลระบบ
ส่งข้อมูล และสรุปงานประจำเดือน ลงข้อมูล Port ต่างจังหวัด Dashboard Sync ประวัติการแก้ไข จัดการผู้ใช้ ตั้งค่า
