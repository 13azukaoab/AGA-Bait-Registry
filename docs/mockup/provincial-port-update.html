  • ยอดจากรายงาน (รวมทั้งสิ้น) ใช้ตรวจตอนกรอกเท่านั้น เก็บเป็น report_cust, report_value (nullable) เพื่อใช้เป็นหลักฐานตรวจย้อนหลัง
  • สถานะ "อัปเดตแล้ว" = แถว source='manual' ที่ confirmed_at ไม่ว่าง · ค่ายกมา = สร้างตอนส่ง Dashboard หรือคำนวณสด (ไม่เขียนแถวซ้ำจนกว่า host ยืนยัน) — ตัดสินตอน build
  • เกณฑ์ band อ่านจาก tier_rules (annual) ห้าม hardcode · สัญญา 3 ปี: ใช้ มูลค่าสัญญา ÷ 3 เทียบ band
  • RLS: เฉพาะ host INSERT/UPDATE ได้ · ทุกการแก้ลง audit_log ด้วย trigger (รวมเดือนที่ปิดแล้ว — SPEC v1.2)
