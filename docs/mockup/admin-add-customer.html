✎ แก้ปัญหาจากไฟล์ Excel เดิมที่ต้นเหตุ
  • มูลค่า = ช่องเดียว + เลือกระยะ (1/3 ปี) แยก → เลิกมี 2 ช่อง "1ปี/3ปี" ที่ลงผิดช่อง 4 แถว ทำ Tier เพี้ยน
  • วันสิ้นสุด auto = วันเริ่ม + N ปี − 1 วัน → กันพิมพ์ผิด (เคยมี 15/10/8202 และสัญญา 0 วัน)
  • เขต auto จากสาขา → เลิกมี "นนทบรี" โผล่ในช่องเขต
  • สาขา/ทีม/ประเภท/ผู้ขาย = dropdown จาก master → เลิก "พระราม2" ≠ "พระราม 2", "Sup"/"sup", ประเภท 28 แบบ
  • เวลาเป็น time picker → เลิก 27 รูปแบบ (09.00 น. / 09:00:00)
  • New/Renew รวมเป็น dropdown "ประเภทงาน" ช่องเดียว → ประหยัดคอลัมน์ และไม่มีเคสติ๊กทั้งคู่/ไม่ติ๊กเลย
  • Tier โชว์สด ทันทีที่ใส่มูลค่า → admin เห็นเลยว่าลูกค้านี้ S/M/L/XL กี่ปี
