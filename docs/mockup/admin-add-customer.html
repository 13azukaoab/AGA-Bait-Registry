✎ แก้ปัญหาจากไฟล์ Excel เดิมที่ต้นเหตุ
  • มูลค่า = ช่องเดียว + เลือกระยะ (1/3 ปี) แยก → เลิกมี 2 ช่อง "1ปี/3ปี" ที่ลงผิดช่อง 4 แถว ทำ Tier เพี้ยน
  • วันสิ้นสุด auto = วันเริ่ม + N ปี − 1 วัน → กันพิมพ์ผิด (เคยมี 15/10/8202 และสัญญา 0 วัน)
  • เขต auto จากสาขา → เลิกมี "นนทบรี" โผล่ในช่องเขต
  • สาขา/ทีม/ประเภท/ผู้ขาย = เลือกจาก master (ช่องสาขาพิมพ์แล้วระบบเดาคำให้ รับเฉพาะชื่อในรายการ) → เลิก "พระราม2" ≠ "พระราม 2", "Sup"/"sup", ประเภท 28 แบบ
  • เวลาเป็น time picker (08:00–17:00 · นาที 00/30) → เลิกหลายรูปแบบ (09.00 น. / 09:00:00) · ไฟล์ ต.ค.2026 จริงใช้แค่ช่วงนี้และนาที 00/30 เท่านั้น
  • เลขที่สัญญา ตัดช่องว่าง + พิมพ์ใหญ่อัตโนมัติ แล้วตรวจรูปแบบ/ซ้ำ → ไฟล์จริงมีเว้นวรรคท้าย 4 รายการ และ ct26- ตัวเล็ก 1 รายการ ถ้าไม่ล้างก่อนเทียบจะกลายเป็นสัญญาคนละใบ
  • ทีม/ประเภทลูกค้าเป็น dropdown จาก master → ไฟล์จริงมี sup/Sup/หนง./o และเวลา 11:30:00 หลุดมาอยู่ในช่องทีม · ประเภทมี "ทาวโฮม" ขาด น์
  • New/Renew รวมเป็น dropdown "ประเภทงาน" ช่องเดียว → ประหยัดคอลัมน์ และไม่มีเคสติ๊กทั้งคู่/ไม่ติ๊กเลย
  • แนบ "สัญญา + Site plan" เป็น PDF ไฟล์เดียวตอนเปิดงาน (คอลัมน์ "ไฟล์แนบ" ) → ไฟล์มากับสัญญาตั้งแต่วันแรก ไม่ต้องไล่หาทีหลัง · ตอนติดตั้งมีแก้ Site plan ใช้ปุ่ม "อัปเดต Site plan" (ใส่เหตุผล เก็บทุกเวอร์ชัน) · ยังไม่แนบ = เตือน บันทึกต่อได้
  • Tier โชว์สด ทันทีที่ใส่มูลค่า → admin เห็นเลยว่าลูกค้านี้ S/M/L/XL กี่ปี
