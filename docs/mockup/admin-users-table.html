มือถือ 375px: 2 แบบให้เลือก

แบบ A · การ์ดรายคน + ช่อง "เรียงตาม"

ข้อดี
  • อ่านครบในหน้าเดียว ไม่ต้องเลื่อนข้าง — เห็นชื่อ ตำแหน่ง สถานะ และ "ไม่ได้เข้ามากี่วัน" พร้อมปุ่มในการ์ดเดียว
  • ปุ่มใหญ่ กดง่ายด้วยนิ้วโป้ง (สูง 44px) ไม่กดผิดแถว
  • เรียงด้วยช่องเลือก + ปุ่มสลับทิศ — คุ้นเคยกว่าการกดหัวตารางบนจอสัมผัส
ข้อเสีย
  • ใช้พื้นที่แนวตั้งมาก (1 คน ≈ 1 หน้าจอเล็ก) — คน 15–40 คนต้องเลื่อนนาน
  • เทียบหลายคนข้างกัน (เช่น ดูใครหายไปนานสุด) ทำยากกว่าตาราง
  • ต้องทำ 2 หน้าตา (ตาราง + การ์ด) เพิ่มงานดูแล

แบบ B · ตารางเลื่อนแนวนอน ตรึงคอลัมน์ชื่อ

ข้อดี
  • หน้าตาเดียวกับ desktop — ทีมไม่ต้องเรียนรู้ใหม่ กดหัวคอลัมน์เรียงได้เหมือนกัน
  • เห็นหลายคนพร้อมกัน เทียบตัวเลขได้ง่าย
  • โค้ดน้อยกว่า (ตารางเดียว)
ข้อเสีย
  • ต้องปัดซ้าย-ขวา ปุ่มจัดการอยู่ขวาสุด ต้องปัดไปถึงจึงกดได้ — คนใช้ครั้งแรกอาจไม่รู้ว่าเลื่อนได้ (จึงใส่ข้อความบอกไว้เหนือตาราง)
  • ปัดเลื่อนข้างอาจชนกับท่าปัดย้อนกลับของเบราว์เซอร์บางรุ่น
  • ตัวหนังสือเล็กและแน่นกว่า

จอ desktop 1440px ครบในจอไม่ล้น — คอลัมน์ตามลำดับ

  1. ชื่อ-นามสกุล (เรียงได้) — แถวของคุณมี "(คุณ)"
  2. รหัสพนักงาน (เรียงได้) — แยกออกมาจากบรรทัดเล็กใต้ชื่อ
  3. ตำแหน่ง (เรียงตามลำดับ เจ้าของ → PM → OM → แอดมิน → หัวหน้างาน)
  4. สถานะ (ใช้งานก่อน) — ป้าย "รอเปลี่ยนรหัส" / "รอแจ้งผู้ใช้" ยังอยู่ครบ
  5. วันเปิดบัญชี (ใหม่) · เข้าใช้ล่าสุด · ไม่ได้เข้าใช้มา (วัน) (ใหม่ ให้ป้ายเตือนเมื่อเกิน 30 / 90 วัน พร้อมข้อความ ไม่ใช้สีอย่างเดียว)
  6. ปุ่มจัดการ — แก้ไข / รีเซ็ตรหัส / ปิดบัญชี (เหมือนเดิม)

ถ้ากรอบเนื้อหากว้างไม่ถึง 1180px (เช่น เปิดเมนูซ้ายเต็ม หรือจอ 1024px) ระบบ ซ่อนคอลัมน์ "เข้าใช้ล่าสุด" แล้วย้ายวันที่ไปเป็นบรรทัดเล็กใต้ "ไม่ได้เข้าใช้มา" · ถ้าไม่ถึง 900px ตรึงชื่อไว้ซ้ายแล้วเลื่อนข้างได้ — กดปุ่ม "กรอบ 1024px" ด้านบนเพื่อดู

วิธีที่ mockup เรียงข้อมูล (ให้ตรวจว่าเข้าใจตรงกัน)

  • กดหัวคอลัมน์ครั้งแรก: ชื่อ / รหัส / ตำแหน่ง / สถานะ = เรียงขึ้นก่อน · วันเปิดบัญชี / เข้าใช้ล่าสุด / ไม่ได้เข้าใช้มา = เรียง "ล่าสุด หรือ นานสุด" ก่อน · กดซ้ำสลับทิศ · ลูกศร ▲▼ บอกทิศ
  • ยังไม่เคยเข้า นับเป็น "ไม่ได้เข้านานที่สุด" — เรียง "ไม่ได้เข้าใช้มา" จากมากไปน้อย จะขึ้นบนสุด · เรียง "เข้าใช้ล่าสุด" จากใหม่ไปเก่า จะอยู่ล่างสุด
  • บัญชีที่ ปิดบัญชีแล้ว ไม่ขึ้นป้ายเตือน "เกิน 30/90 วัน" (เพราะตั้งใจปิดอยู่แล้ว ไม่ต้องตามให้มีคนใช้) — ยังโชว์จำนวนวันเป็นตัวหนังสือเทา
  • บัญชีที่ ยังไม่เคยเข้า และเปิดมานานกว่า 30 วัน ขึ้นป้ายเตือนเหลือง "ยังไม่เคยเข้า" พร้อมบอกว่าเปิดมากี่วัน
  • บัญชีเจ้าของ (แสดงเป็นตำแหน่ง "เจ้าของ") ปุ่มจัดการปิดไว้ตามหน้าจริงปัจจุบัน
หมายเหตุสำหรับเจ้าของ — คอลัมน์ "วันเปิดบัญชี" ตอนนี้ระบบยังไม่ได้ส่งค่านี้มาที่หน้า (หน้าจริงรู้แค่ชื่อ ตำแหน่ง สถานะ และเข้าใช้ล่าสุด) จึง ต้องให้ฝั่งฐานข้อมูลเพิ่มก่อนทำจริง · ส่วน "ไม่ได้เข้าใช้มา (วัน)" ไม่ต้องเพิ่มอะไร คำนวณจาก "เข้าใช้ล่าสุด" ที่มีอยู่แล้ว · งานนี้ทำจริง หลัง go-live · ตอนนี้เป็นแค่ภาพให้ดูและเลือกแบบก่อน

สิ่งที่อยากให้เจ้าของเลือก

  1. มือถือใช้ แบบ A (การ์ด) หรือ แบบ B (ตารางเลื่อน)
  2. เกณฑ์เตือนเกิน 30 / 90 วัน ใช้ตามนี้ได้ไหม หรืออยากเปลี่ยนตัวเลข (ในของจริงเก็บเป็นค่าตั้งค่า ไม่ฝังในโค้ด)
  3. บัญชีที่ปิดอยู่ ไม่ต้องเตือน — เห็นด้วยไหม
  4. ลำดับตำแหน่งตอนเรียง (เจ้าของ → PM → OM → แอดมิน → หัวหน้างาน) ใช้ลำดับนี้ หรือเรียงตามตัวอักษรไทย
