Dashboard Sync

ติดตามการส่งตัวเลขไป AGA Bait Dashboard · ดูประวัติ · ดาวน์โหลดไฟล์สำรอง · เฉพาะ host · ข้อมูลในหน้านี้เป็นตัวอย่าง

🔒

หน้านี้สำหรับ host เท่านั้น

บทบาทนี้ไม่มีสิทธิ์ดูการตั้งค่า/ประวัติการส่งข้อมูล สิทธิ์บังคับที่ฐานข้อมูล (RLS) ไม่ใช่แค่ซ่อนปุ่ม

สถานะการส่งล่าสุด

ระบบส่งข้อมูลเข้า Dashboard อย่างไร

⏰
Auto Sync ทุกวัน 06:00 น. (เวลาไทย) รันบน Vercel Cron เอง ไม่ต้องเปิดคอมพิวเตอร์ · ตั้งเวลา 0 23 * * * (UTC) · ระบบอาจเริ่มรันช่วง 06:00–06:59 ถือว่าปกติ ไม่คำนวณ "เดือนที่ปิดแล้ว" ใหม่เอง — ใช้ snapshot ที่เก็บไว้ (รอเจ้าของยืนยัน SPEC §14 ข้อ 9)
🔒
ปิดเดือน → ส่งทันที เมื่อ host หรือหัวหน้างานกดปิดเดือน ระบบเก็บ snapshot แล้วส่ง Dashboard ทันที ไม่ต้องรอรอบ 06:00 · ถ้าส่งไม่สำเร็จ เดือนยังถือว่าปิดแล้ว
↻
คำนวณ snapshot ใหม่ → ส่งทันที ใช้เมื่อมีการแก้ผลบริการหลังปิดเดือน (กดที่หน้า ปิดเดือน)
⇩
Export สำรอง (ทำเอง) ดาวน์โหลดไฟล์ dashboard_data.json ไว้เป็นหลักฐาน/ใช้ยามฉุกเฉินเมื่อส่งอัตโนมัติไม่ได้ — ดูกล่องด้านขวา
