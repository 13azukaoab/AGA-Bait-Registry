จัดการผู้ใช้

host สร้างบัญชีให้ทีมงาน กำหนดสิทธิ์ (role) ขอบเขตหน่วยงาน และทีม — ไม่มีหน้าสมัครเอง · 🔒 สิทธิ์ host

ชื่อที่แสดงตำแหน่งหน่วยงาน (division_scope) ทีมสถานะเข้าใช้ล่าสุดจัดการ
ไม่พบบัญชีที่ตรงกับตัวกรอง ลองล้างคำค้นหาหรือเปลี่ยนตัวกรอง
ทุกการสร้าง/แก้ไข/ปิดบัญชี บันทึกใน audit log อัตโนมัติ
viewer ไม่มีบัญชี — ผู้บริหาร/ฝ่ายขาย/คนนอกดูหน้าสรุปตัวเลข (public) ได้โดยไม่ต้อง login · ทีมบริการหน้างานไม่มีบัญชีในเฟส 1 (ส่งสรุปงานให้หัวหน้างาน = recorder กรอกแทน)

แต่ละ role ทำอะไรได้ (SPEC §5)

host (PM / OM)ดู/แก้ทุกอย่าง + จัดการผู้ใช้ เกณฑ์ Tier ตั้งค่า ปิด/เปิดเดือน ตัวเลขต่างจังหวัด — PM กับ OM สิทธิ์เท่ากัน ต่างแค่ชื่อตำแหน่งที่แสดง
adminดูทุกเขต · เพิ่ม/แก้ลูกค้า สัญญา สถานี เฉพาะหน่วยงานที่ได้รับสิทธิ์
recorderดูทุกเขต · กรอกผลบริการ เฉพาะหน่วยงานที่ได้รับสิทธิ์ · หน้าจอเริ่มต้นกรองตามทีมของตัวเอง
