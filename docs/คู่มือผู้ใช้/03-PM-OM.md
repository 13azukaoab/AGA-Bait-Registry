# 03 — Project Manager (PM) / Operation Manager (OM)

> **ฉบับใช้อบรม** · ปรับล่าสุด 28 พ.ย. 2026 · ชื่อปุ่ม/เมนูตรวจกับหน้าจอจริงแล้ว · ชื่อ/รหัสพนักงาน/ลูกค้าในคู่มือเป็น **ข้อมูลสมมติ**
> ยังไม่ได้อ่านบท `00-เริ่มใช้งานครั้งแรก.md`? อ่านก่อน (เข้าสู่ระบบ + ตั้งรหัสผ่านใหม่)

## ทำอะไรได้บ้าง

PM และ OM คือ **ส่วนกลางที่ดูแลระบบ** (ข้อความบนจอเรียกว่า "Host (QCS ส่วนกลาง Bait)") — **สิทธิ์เท่ากันทุกข้อ ต่างกันแค่ชื่อตำแหน่งที่แสดง**

> **หมายเหตุเรื่องตำแหน่ง "เจ้าของ":** มีสิทธิ์ระดับ Host เหมือน PM / OM ทุกอย่าง และใช้บทสอนเดียวกัน ("PM / OM") · ข้อต่างคือ หน้า "จัดการผู้ใช้" **ตั้งตำแหน่งเจ้าของให้ใครไม่ได้** และ **แก้ไข รีเซ็ตรหัส หรือปิดบัญชีเจ้าของไม่ได้** (จอแสดง "บัญชีเจ้าของ แก้ไข รีเซ็ตรหัส หรือปิดจากหน้านี้ไม่ได้")

PM / OM **เห็นครบทุกเมนู**:

| กลุ่มเมนู | เมนู |
|---|---|
| งานประจำวัน | สถานะทะเบียนบริการ · ลงข้อมูลทำบริการประจำเดือน · กล่อง AG นอกรอบประจำเดือน · ลูกค้ารอเก็บสถานี |
| ทะเบียนและสรุป | ทะเบียนลูกค้า/สัญญา · เปิดงานเข้าทะเบียนบริการ · สรุปงานบริการรายเดือน · Dashboard งานขาย (New/Renew) · Dashboard สรุปมูลค่าทั้งหมด |
| ดูแลระบบ | ส่งข้อมูล และสรุปงานประจำเดือน · ลงข้อมูล Port ต่างจังหวัด · Dashboard Sync · ประวัติการแก้ไข · **จัดการผู้ใช้** · **ตั้งค่า** |

> **งานกรอกผลบริการ / เปิดงาน / ตัดสินเรื่องตกบริการ** — PM / OM ทำได้ทั้งหมดเหมือนหัวหน้างานและแอดมิน (อ่านขั้นตอนในบท `02-หัวหน้างาน.md` และ `01-Admin-เปิดงาน.md`) · ต่างกันที่ PM / OM **บันทึกบริการชดเชยที่เลยเพดานชดเชยแล้วได้** (เป็นกรณีพิเศษ — ปุ่มขึ้น "(เกินเพดาน)") และแก้สัญญาที่ **ปิดแล้ว/ยกเลิกแล้ว** ได้
> บทนี้เน้นงานที่ **เป็นของ PM / OM เท่านั้น**

## งานประจำ 1: จัดการผู้ใช้ (สร้างบัญชี · แก้ไข · รีเซ็ตรหัส · ปิด/เปิดบัญชี)

หน้าที่ใช้: เมนู **จัดการผู้ใช้** (กลุ่ม "ดูแลระบบ")

หน้านี้บอกว่า "สร้างบัญชีให้ทีมงานและกำหนดตำแหน่ง — ไม่มีหน้าสมัครเอง" · เฉพาะ PM / OM / เจ้าของเท่านั้น

[ภาพหน้าจอ: หน้า "จัดการผู้ใช้" การ์ดสรุปตามตำแหน่ง + ตัวกรอง + ตารางบัญชี]

ส่วนต่างๆ ของหน้า:
- แถวการ์ดสรุปบน: **ทั้งหมด** · จำนวนตามแต่ละตำแหน่ง · **ปิดบัญชี** (กดเพื่อกรอง)
- ตัวกรอง: **ค้นหา** (ชื่อ-นามสกุล / รหัสพนักงาน) · **ตำแหน่ง** · **สถานะ** (ทั้งหมด / ใช้งาน / ปิดบัญชี)
- ตาราง: **ชื่อ-นามสกุล · รหัสพนักงาน · ตำแหน่ง · สถานะ · เข้าใช้ล่าสุด · ไม่ได้เข้าใช้มา (วัน)** + ปุ่ม **แก้ไข · รีเซ็ตรหัส · ปิดบัญชี/เปิดบัญชี** (บัญชีของคุณมีคำว่า "(คุณ)" ต่อท้ายชื่อ · จอแคบ "เข้าใช้ล่าสุด" ย้ายไปอยู่ใต้ตัวเลขวัน)
  - ป้าย **รอเปลี่ยนรหัส** = ผู้ใช้ยังไม่ได้ตั้งรหัสใหม่หลังได้รหัสชั่วคราว

> ตารางแสดงรหัสพนักงานเป็น **ตัวพิมพ์ใหญ่** (เช่น `AG-01234` — *สมมติ*) แม้ตอนสร้างจะพิมพ์ตัวเล็ก · เป็นบัญชีเดียวกัน ตอนเข้าสู่ระบบพิมพ์ตัวเล็กหรือใหญ่ก็ได้

**เรียงลำดับตาราง:** กดที่ **หัวคอลัมน์** เพื่อเรียง กดซ้ำเพื่อสลับทิศ · ค่าเริ่มต้นเรียงตามตำแหน่ง (เจ้าของ → PM → OM → แอดมิน → หัวหน้างาน) · บนมือถือเป็นการ์ดรายคน ใช้ช่อง **เรียงตาม** และปุ่มสลับทิศข้างช่อง

**คอลัมน์ "ไม่ได้เข้าใช้มา (วัน)":** บอกว่าบัญชีนั้นไม่ได้เข้าระบบมากี่วันแล้ว (นับตามวันที่ปฏิทินไทย · เข้าวันนี้ขึ้น "วันนี้")

| ที่เห็น | ความหมาย |
|---|---|
| ป้ายเหลือง **เกิน 30 วัน** | ไม่ได้เข้า 30 วันขึ้นไป — ลองสอบถามว่ายังใช้อยู่ไหม |
| ป้ายแดง **เกิน 90 วัน** | ไม่ได้เข้า 90 วันขึ้นไป — พิจารณาปิดบัญชีถ้าไม่ใช้แล้ว |
| **ยังไม่เคยเข้า** | สร้างบัญชีแล้วแต่ยังไม่เคยเข้าระบบ |

บัญชีที่ปิดแล้วไม่ขึ้นป้ายเตือน · ระบบไม่ปิดบัญชีให้เอง

### สร้างบัญชีใหม่

1. กดปุ่ม **สร้างบัญชี** (มุมขวาบน) → หน้าต่าง **"สร้างบัญชีใหม่"**
2. กรอก:
   - **รหัสพนักงาน (ใช้เข้าสู่ระบบ)** — เช่น `ag-01234` (*ตัวอย่างสมมติ*) · ใช้ตัวอักษร/ตัวเลข (a-z 0-9 . _ -) ยาว 3–20 ตัว · **ห้ามซ้ำ · สร้างแล้วเปลี่ยนไม่ได้**
   - **ชื่อ - นามสกุล (เจ้าของรหัสพนักงาน)** — ชื่อจริง เช่น *นภา แสงทอง (สมมติ)*
   - **ตำแหน่ง** — เลือก: แอดมิน (Admin) · หัวหน้างาน (Supervisor) · Project Manager (PM) · Operation Manager (OM)
     (ตำแหน่ง "เจ้าของ" สร้างผ่านหน้านี้ไม่ได้)
3. กด **สร้างบัญชี** → ระบบสุ่ม **รหัสผ่านชั่วคราว** ให้ แสดงในหน้าต่าง **"สร้างบัญชีแล้ว"**
4. กด **คัดลอก** แล้ว **ส่งรหัสให้เจ้าของบัญชีด้วยตัวเอง** (โทร/แชตส่วนตัว) → กด **เสร็จสิ้น**

> ⚠ **รหัสชั่วคราวแสดงครั้งเดียว** ปิดหน้าต่างแล้วดูไม่ได้อีก — ถ้าหาย ให้กด **รีเซ็ตรหัส** ใหม่
> ผู้ใช้ต้องเปลี่ยนรหัสตอนเข้าครั้งแรก (บังคับ)
> ผู้ชมทั่วไป (ผู้บริหาร/ฝ่ายขาย/คนนอก) **ไม่ต้องมีบัญชี** · ทีมบริการหน้างานไม่มีบัญชี

### แก้ไขบัญชี (ชื่อ / ตำแหน่ง)

1. กด **แก้ไข** ที่แถวของผู้ใช้ → หน้าต่าง **"แก้ไขบัญชี · (รหัสพนักงาน)"** (แก้รหัสพนักงานไม่ได้ เพราะใช้เข้าสู่ระบบและอ้างอิงในประวัติ)
2. แก้ **ชื่อ - นามสกุล** หรือ **ตำแหน่ง** แล้วกด **บันทึก**
3. **ถ้าเปลี่ยนตำแหน่ง** (= เปลี่ยนสิทธิ์) ระบบขึ้นหน้าต่าง **"ยืนยันเปลี่ยนตำแหน่ง"** แสดง "ตำแหน่งเดิม → ตำแหน่งใหม่" → พิมพ์คำว่า **`ยืนยันแก้ไข`** ให้ตรง แล้วกด **ยืนยันเปลี่ยน** (หรือ **กลับไปแก้**)
4. สิทธิ์ของผู้ใช้เปลี่ยนทันที · ทุกการแก้ลงประวัติการแก้ไขอัตโนมัติ

> ⚠ ถ้าแก้บัญชี **ตัวเอง** แล้วลดสิทธิ์ จอเตือน "นี่คือบัญชีของคุณ — ถ้าลดสิทธิ์ตัวเอง คุณจะเข้าหน้านี้ไม่ได้อีก"
> ⚠ ต้องมี PM / OM / เจ้าของ ที่ใช้งานอยู่ **อย่างน้อย 1 คน** เสมอ — เปลี่ยนตำแหน่งคนสุดท้ายออกไม่ได้

> **เรื่องแจ้งผู้ใช้ว่าตำแหน่งถูกเปลี่ยน:** ระบบบันทึกแจ้งเตือนไว้ แต่ **ยังไม่มีหน้าจอแสดงให้ผู้ใช้เห็น** (จอบอกเองว่า "กรุณาแจ้งเขาเอง") — ให้โทร/แชตแจ้งผู้ใช้ด้วยตัวเอง · แถวของผู้ใช้ที่ยังไม่ได้อ่านแจ้งเตือนจะขึ้นป้าย **รอแจ้งผู้ใช้**

### รีเซ็ตรหัส (เมื่อผู้ใช้ลืมรหัส)

1. กด **รีเซ็ตรหัส** ที่แถวของผู้ใช้ → ยืนยันในหน้าต่าง **"รีเซ็ตรหัสผ่าน"**
2. ระบบสุ่มรหัสชั่วคราวใหม่ — **รหัสเดิมใช้ไม่ได้ทันที** · ผู้ใช้ต้องเปลี่ยนรหัสตอนเข้าครั้งต่อไป
3. กด **คัดลอก** แล้วส่งให้ผู้ใช้ด้วยตัวเอง → **เสร็จสิ้น**
4. ถ้าบัญชีนั้นปิดอยู่ จอเตือน "บัญชีนี้ปิดอยู่ — รีเซ็ตแล้วยังล็อกอินไม่ได้จนกว่าจะเปิดบัญชี"

### ปิด / เปิดบัญชี (เช่น คนลาออก)

- กด **ปิดบัญชี** → ยืนยัน: ล็อกอินไม่ได้ทันที (ที่เปิดอยู่ถูกตัดออก) · **ข้อมูลที่เคยกรอกและประวัติแก้ไขยังอยู่ครบ ไม่ลบ** · เปิดคืนได้ทุกเมื่อ
- ผู้ใช้ที่ถูกปิดแล้วลองเข้าสู่ระบบจะเห็น **"ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง"** (ตั้งใจ — ระบบไม่บอกว่ามีชื่อผู้ใช้นี้) และมีบรรทัดช่วย **"ถ้าลืมรหัสหรือบัญชีถูกปิด ติดต่อ Host"** — Host ในข้อความนี้คือ PM / OM
- กด **เปิดบัญชี** → เปิดกลับมาใช้งาน (ถ้าไม่ได้เข้านานหรือจำรหัสไม่ได้ แนะนำกด **รีเซ็ตรหัส** ต่อ)
- ปิดบัญชีตัวเองไม่ได้ ("ให้ผู้ดูแลระบบคนอื่นเป็นคนปิดให้") และปิดคนสุดท้ายของ PM/OM/เจ้าของไม่ได้

ท้ายหน้ามีกล่อง **"แต่ละตำแหน่งทำอะไรได้"** สรุปสิทธิ์ของทุกตำแหน่ง · ต้องการตำแหน่งใหม่ (เช่น ผู้ช่วย PM) เพิ่มได้ภายหลังโดยไม่ต้องแก้ระบบ

## งานประจำ 2: ตั้งค่า (เกณฑ์ Tier · ประเภทลูกค้า · ทีม)

หน้าที่ใช้: เมนู **ตั้งค่า** (กลุ่ม "ดูแลระบบ") — "ข้อมูลหลักที่ทั้งระบบใช้ร่วมกัน · แก้ได้เฉพาะผู้ดูแลระบบ (PM / OM / เจ้าของ) · ทุกการแก้ไขบันทึกลงประวัติการแก้ไข"

มี 3 แท็บ: **เกณฑ์ Tier** · **ประเภทลูกค้า** · **ทีม**

[ภาพหน้าจอ: หน้า "ตั้งค่า" แท็บ "เกณฑ์ Tier" ตารางเกณฑ์ + ตัวอย่างตรวจสอบ]

### แท็บ "เกณฑ์ Tier"

เกณฑ์แบ่ง S / M / L / XL (และ XXL — ดูหัวข้อย่อย "Tier XXL") ตามมูลค่าสัญญาต่อปี — ระบบอ่านเกณฑ์จากที่นี่เสมอ (ไม่ฝังตัวเลขในโปรแกรม)

1. แก้ได้เฉพาะ **จุดเริ่มของ M, L, XL** (และ XXL เมื่อหน้าจอรองรับ) · S เริ่มที่ 0 คงที่ — ปลายช่วงของ Tier ก่อนหน้าระบบคำนวณให้ จึงไม่มีช่องว่างหรือช่วงทับกัน
2. ดู **"ตัวอย่างตรวจสอบ"** ด้านล่าง — คำนวณสดจากเกณฑ์ที่กำลังแก้ (ลองใส่มูลค่าและระยะสัญญาเองได้) แก้เกณฑ์จนตัวอย่างถูกต้องก่อน
3. ป้ายสถานะ **"● มีการแก้ที่ยังไม่บันทึก"** / **"✓ ตรงกับที่บันทึกไว้"** · ปุ่ม **คืนค่าเริ่มต้น** (คืนชุดตั้งต้นของระบบ ยังไม่บันทึกจนกว่าจะกดบันทึก) · **ยกเลิกการแก้**
4. กด **บันทึกเกณฑ์…** → หน้าต่าง **"บันทึกเกณฑ์ Tier"** แสดง "สิ่งที่จะเปลี่ยน":
   - เลือก **เริ่มใช้ตั้งแต่เดือน** (เลือกได้เฉพาะเดือนที่ยังเปิด)
   - กรอก **เหตุผลในการแก้ (บังคับ — เก็บในประวัติการแก้ไข)**
   - พิมพ์ **`ยืนยันแก้ไข`** ให้ตรง แล้วกด **บันทึก**
5. กล่อง **"ผลกระทบต่อสัญญาที่ใช้งานอยู่"** — เลือก **นับตั้งแต่เดือน** แล้วระบบประมาณให้ว่า **กี่สัญญาจะเปลี่ยน Tier** (ขึ้นป้าย "⚠ N สัญญาจะเปลี่ยน Tier" หรือ "✓ ไม่มีสัญญาเปลี่ยน Tier") · เป็น **ตัวเลขประมาณ** ไม่แสดงชื่อลูกค้า · ดูก่อนกดบันทึกทุกครั้ง
6. ตารางล่าง **"เกณฑ์ที่ใช้ในแต่ละช่วงเดือน"** แสดงประวัติ: ใช้ตั้งแต่เดือนไหน · สถานะ (ใช้อยู่ตอนนี้ / จะเริ่มใช้ / ใช้ไปแล้ว)

> ⚠ **เกณฑ์ใหม่มีผลตั้งแต่เดือนที่เลือกเป็นต้นไป** · เดือนที่ปิดแล้วคงเกณฑ์เดิม และตัวเลขที่ส่ง Dashboard ไปแล้วไม่เปลี่ยนจนกว่าจะสั่งคำนวณใหม่ — **คิดให้ดีก่อนบันทึก**

> ⏳ รอหน้าจริง · ช่องกรอกเกณฑ์ XXL ในแท็บ "เกณฑ์ Tier" (ชื่อช่องและปุ่มจะเติมเมื่อหน้าจอเสร็จ)

**กติกา:**
- มูลค่าต่อปีตั้งแต่เกณฑ์ XXL ขึ้นไป = XXL · ค่าตั้งต้นที่ตกลงไว้คือ **300,000 บาท/ปี** (ถ้าเกณฑ์ XL ยังเป็น 100,000 ช่วง XL จะเป็น 100,000 – 299,999.99) แก้ได้ภายหลังเหมือน M / L / XL
- **ระบบไม่ใส่เกณฑ์ XXL ให้เอง** — PM / OM ต้องกรอกและบันทึกเกณฑ์เอง
- เกณฑ์ XXL ต้องมากกว่าเกณฑ์ XL
- มีผล **ตั้งแต่เดือนที่เลือกเริ่มใช้** · ชุดเกณฑ์เดิมไม่มี XXL เดือนที่ใช้ชุดเดิมจึง **ไม่มี XXL** (สัญญามูลค่าสูงยังเป็น XL) · เดือนที่ปิดแล้วคงเดิม
- ถ้าบันทึกเกณฑ์ของเดือนเดิมซ้ำโดยเว้นช่อง XXL ว่าง = ชุดของเดือนนั้นจะ **ไม่มี XXL**

**สีป้าย:** ทอง — **XXL1** (1 ปี หรือ Custom) ทองอ่อน · **XXL3** (3 ปี) ทองเข้ม · ทั้งสองแบบมี "ประกายวิ่ง" (คำอธิบายสีและแถบสีในหน้าตั้งค่าเล่นเอง · ในตารางและตัวกรองเล่นตอนชี้ · เครื่องที่ตั้งค่าลดการเคลื่อนไหวจะไม่เล่น)

**บน Dashboard:** AGA Bait Dashboard และหน้า "Dashboard สรุปมูลค่าทั้งหมด" **ไม่มีช่อง XXL แยก — นับรวมใน XL** (XXL1 รวมใน XL1 · XXL3 รวมใน XL3 · มูลค่ารวมใน XL)

### แท็บ "ประเภทลูกค้า"

รายการประเภทที่ขึ้นใน dropdown หน้าเปิดงาน (จัดเป็นหมวด)

- **เพิ่มประเภท** → ใส่ **ชื่อประเภท** + เลือก **หมวด** (หรือ **+ หมวดใหม่…** แล้วใส่ **ชื่อหมวดใหม่**) → **บันทึก**
- **แก้ไข** ชื่อ/หมวดของประเภท · ช่อง **คำอธิบาย** (ไม่บังคับ — โชว์เป็นคำอธิบายตอนเลือกประเภทในหน้าเปิดงาน) · **ลบ** (ลบได้เฉพาะประเภทที่ยังไม่มีลูกค้าใช้ — ถ้ามีลูกค้าใช้อยู่ให้เปลี่ยนชื่อแทน)
- **สวิตช์เปิด/ปิดใช้** ที่แถวของประเภท — ประเภทที่ปิดใช้ (ขึ้นป้าย "ปิดใช้") **ไม่โผล่ใน dropdown** ของงานใหม่ แต่ลูกค้าเดิมที่ใช้ประเภทนั้นยังแสดงตามเดิม
- เรียงลำดับ: กด **จัดเรียงลำดับ** → ใช้ปุ่มลูกศรย้ายหมวด/ประเภท ขึ้น-ลง → **บันทึกลำดับ** (หรือ **ยกเลิกการเรียง**) → **เสร็จการจัดเรียง**
- กติกา: ชื่อประเภทต้องไม่ซ้ำกันทั้งระบบ · **"สถานที่ทางศาสนา" มาก่อนเสมอ** · ประเภทที่ไม่เข้าหมวดใดเลยให้ใช้ "อื่นๆ"
- กล่อง **"ตัวอย่างใน dropdown"** แสดงหน้าตารายการที่หน้าเปิดงานจะเห็น

### แท็บ "ทีม"

- **เพิ่มทีม** → กรอก **รหัสทีม** (แก้ภายหลังไม่ได้) · **ชื่อ / คำอธิบาย** · **ประเภททีม** · **จำนวนคนภาคสนาม** (0 = ยังไม่ระบุ) → **บันทึก**
- **แก้ไข** ชื่อ/ประเภท/จำนวนคน · สวิตช์ **ใช้งาน** = เปิด/พักทีม (ทีมที่พักจะไม่ขึ้นให้เลือกในงานใหม่ แต่งานเดิมยังอยู่)
- **ลบ** ได้เมื่อไม่มีงานผูกอยู่ (สัญญา · การเข้าบริการ · ผู้ใช้) — ถ้ามีงานผูกอยู่ ให้ปิดใช้งานทีมแทน
- **ทีมระบบ** (มีไอคอนกุญแจ) ลบ ปิดใช้ หรือเปลี่ยนประเภทไม่ได้
- ส่วน **"เกณฑ์ Workload"** (ชม. / คน / เดือน = **ค่ากลาง** ใช้กับทุกทีมที่ไม่ได้ตั้งเอง): แก้ค่า → กด **บันทึกเกณฑ์…** → พิมพ์ **`ยืนยันแก้ไข`** → **บันทึก** · มีผลกับการแสดง Workload (ในหน้า **สรุปงานบริการรายเดือน** แท็บ **สรุปรายทีม**) ทันที
- **ตั้งเกณฑ์เฉพาะทีม:** ที่ตารางทีม คอลัมน์ **ชม./คน/เดือน** กดปุ่ม **ตั้งเกณฑ์** ที่ทีมนั้น → หน้าต่าง **"เกณฑ์ภาระงานทีม …"** ใส่ **เกณฑ์ของทีมนี้ (ชม./คน/เดือน)** แล้ว **บันทึก** · ถ้าอยากให้ทีมนั้นกลับไปใช้ค่ากลาง กด **กลับไปใช้ค่ากลาง**

## งานประจำ 3: ส่งข้อมูล และสรุปงานประจำเดือน

หน้าที่ใช้: เมนู **ส่งข้อมูล และสรุปงานประจำเดือน** (กลุ่ม "ดูแลระบบ")

PM / OM ปิดได้ทั้ง **ส่วนกลาง 24 สาขา** และ **ต่างจังหวัด 19 สาขา** (หัวหน้างานปิดได้เฉพาะส่วนกลาง) · **การกดปิดงานเดือนจะส่งตัวเลขขึ้น AGA Bait Dashboard จริงทันที**
ขั้นตอนทีละขั้น ข้อความบนจอ และเรื่อง "ปิดข้าม" อยู่ในบท `02-หัวหน้างาน.md` หัวข้อ "งานประจำ 7" — อ่านบทนั้นก่อน · ส่วนที่เป็นของ PM / OM โดยเฉพาะมีดังนี้:

- **ปิดข้าม** (เมื่อบางสาขาบันทึกไม่ครบ) — เฉพาะ PM / OM · ช่อง **เหตุผลที่ปิดข้าม** (5–500 ตัวอักษร) จะขึ้น **หลังกดปุ่มปิดแล้ว** → ใส่เหตุผลแล้วกดปิดอีกครั้ง
- **ปิดต่างจังหวัด** — เฉพาะ PM / OM · ถ้ามีสาขาใช้ค่ายกมา ช่องติ๊กรับทราบจะขึ้นหลังกดปุ่มปิด → ติ๊กแล้วกดปิดอีกครั้ง
- **ตัวเลขตกบริการ** ในแต่ละขั้นและในหน้า "สถานะทะเบียนบริการ" นับคนละขอบเขต (ส่วนกลาง 24 สาขา / รวมถึง 43 สาขา) ไม่เท่ากันได้
- **คำนวณ snapshot ใหม่ + ส่ง Dashboard** (ในรายละเอียดเดือนที่ปิดแล้ว) — เฉพาะ PM / OM · ใช้เมื่อมีการแก้ข้อมูลหลังปิด แล้วต้องการให้ตัวเลขบน Dashboard เปลี่ยนตาม · กดแล้วขึ้นกล่อง **"ยืนยันคำนวณ snapshot ใหม่ และส่ง Dashboard"** บอกเดือน ส่วน และปลายทาง → ต้อง **พิมพ์รหัสเดือน** ตามที่จอบอก แล้วกด **ยืนยันส่ง** (กด **ยกเลิก** หรือ Esc = ไม่ส่ง)
- เดือนที่ปิดแล้ว **ไม่ล็อกข้อมูล** — ยังแก้ผลบริการย้อนหลังได้ (ทุกการแก้ลงประวัติ) แต่ตัวเลขบน Dashboard คงค่าเดิมจนกว่าจะกด "คำนวณ snapshot ใหม่ + ส่ง Dashboard"
- ป้าย **แก้หลังปิด N** ที่รายการเดือน บอกว่ามีการแก้หลังปิดกี่ครั้ง ใช้ตัดสินใจว่าควรกดคำนวณใหม่หรือยัง

## งานประจำ 4: ลงข้อมูล Port ต่างจังหวัด

หน้าที่ใช้: เมนู **ลงข้อมูล Port ต่างจังหวัด** (กลุ่ม "ดูแลระบบ") — **เฉพาะ PM / OM**

**Port** = สรุปจำนวนลูกค้าและมูลค่าสัญญา แยกตามขนาด (Tier) ของ **19 สาขาต่างจังหวัด** ที่ยังไม่ได้ใช้ระบบนี้กรอกทะเบียน — แทนการอัปเดตไฟล์ Excel เดือนละครั้ง
(ส่วนกลาง 24 สาขา ระบบคำนวณจากทะเบียนเอง ไม่ต้องลงที่หน้านี้)

[ภาพหน้าจอ: หน้า "ลงข้อมูล Port ต่างจังหวัด" ตารางสาขาซ้าย + แผงแก้ไขขวา (ข้อมูลสมมติ)]

### ส่วนบนของหน้า

- ช่อง **เดือน** — เลือกเดือนที่จะลง (เดือนที่ปิดแล้วมีคำว่า "· ปิดแล้ว")
- การ์ดสรุป: **อัปเดตแล้ว** (เช่น 12 / 19) · **ยังไม่อัปเดต** · **มูลค่ารวม … สาขา (บาท)** · **ส่วนต่างจากเดือนก่อน (บาท)** — กดการ์ด **อัปเดตแล้ว** / **ยังไม่อัปเดต** เพื่อกรองตาราง
- ข้อความสีเหลืองถ้าเดือนนั้นยังไม่มีข้อมูล: ระบบ **ยกค่าเดือนก่อนมาให้** (สถานะ "ยังไม่อัปเดต") — ถ้าไม่ได้ยืนยัน Dashboard จะใช้ค่ายกมานี้ไปก่อน

### ตารางสาขา

- ตัวกรอง: **ค้นหาสาขา** · **เขต** · **สถานะ** (ทั้งหมด / ยังไม่อัปเดต / อัปเดตแล้ว / ส่วนต่างเกิน 10%)
- คอลัมน์: **สาขา · สถานะ · อัปเดตโดย · ราย · มูลค่ารวม (บาท) · เดือนก่อน · ส่วนต่าง · เทียบยอด**
- ธงที่ส่วนต่าง = ต่างจากเดือนก่อนเกิน 10% — **ไม่ใช่ข้อผิดพลาด** แต่ควรตรวจว่ากรอกถูก
- ป้ายสถานะ: **อัปเดตแล้ว** · **ยังไม่อัปเดต** · **ต้องกรอกเอง** · **ข้อมูลเก่า** (ข้อมูลเก่าที่นำเข้ามา แก้ในหน้านี้ไม่ได้)

### ลงข้อมูลสาขาหนึ่ง

1. กดชื่อสาขาในตาราง → แผงแก้ไขเปิดขึ้นมา
2. กรอก **จำนวน (ราย)** และ **มูลค่ารวม (บาท)** ของแต่ละ Tier ทั้ง 8 แบบ (S1 · S3 · M1 · M3 · L1 · L3 · XL1 · XL3 — สัญญาระดับ XXL ให้รวมไว้ในช่อง XL1 / XL3) **หรือวางตารางจาก Excel:**
   - ใน Excel ลากคลุมตาราง กด Ctrl+C แล้วกด **Ctrl+V** บนหน้านี้ (หรือวางในช่องข้อความ) → กด **อ่านข้อมูล** → ตรวจรายการที่ระบบจับคู่ได้ → กด **ใส่ลงฟอร์ม** (ปุ่ม **ล้าง** = เริ่มใหม่)
   - "-" ในตารางจะถูกอ่านเป็น 0 · บรรทัด "รวมทั้งสิ้น" ใช้เป็นยอดรายงานให้เอง
3. ช่อง **ยอดจากรายงาน (รวมทั้งสิ้น)** — ใส่จำนวนและมูลค่ารวมจากรายงานต้นทาง ระบบเทียบให้ว่า **ตรงกับรายงาน** หรือ **ไม่ตรง** (บอกส่วนต่าง) — ไม่กรอกก็บันทึกได้ แต่แนะนำให้กรอก
4. ปุ่มด้านล่างแผง:
   - **บันทึกเป็น “อัปเดตแล้ว”** (ถ้าเคยอัปเดตแล้วจะเป็น **บันทึกการแก้ไข**) — ถ้ามีคำเตือน (เช่น ยังไม่เทียบยอด) จะถามยืนยันก่อน
   - **ยืนยันใช้ค่าเดิม (ไม่มีการเปลี่ยนแปลง)** — ใช้เมื่อเดือนนี้ตัวเลขเท่าเดือนก่อนทุกช่อง · ถือว่าอัปเดตแล้ว
   - **คืนค่าเดิม** — ทิ้งที่แก้ค้างไว้ · **ปิด** — ปิดแผง (ถ้ามีที่แก้ค้างจะถามก่อน)
5. ถ้ากรอกไม่ถูกต้อง → ขึ้นกรอบ "บันทึกยังไม่ได้ — แก้รายการนี้ก่อน" บอกข้อที่ต้องแก้

**ที่ควรรู้:**
- บันทึกแล้วเก็บเป็นข้อมูลของสาขานั้นเดือนนั้น และ **ส่ง Dashboard ในรอบอัตโนมัติถัดไป** (06:00 น. หรือตอนปิดงานประจำเดือน) — ไม่ได้ขึ้นทันที
- เดือนที่ปิดแล้ว **แก้ได้** แต่ลงประวัติการแก้ไขทุกครั้ง และตัวเลขที่แก้จะส่งขึ้น Dashboard รอบ 06:00 ถัดไป
- สาขาที่เดือนก่อนเป็นข้อมูลเก่าที่นำเข้า ต้อง **กรอกจากรายงานเอง** ครั้งแรกครั้งเดียว (ขึ้นป้าย "ต้องกรอกเอง")

## งานประจำ 5: Dashboard Sync (ติดตามการส่งตัวเลขไป Dashboard)

หน้าที่ใช้: เมนู **Dashboard Sync** (กลุ่ม "ดูแลระบบ") — **เฉพาะ PM / OM**

ระบบส่งตัวเลขไป **AGA Bait Dashboard** ให้เอง **ทุกวัน 06:00 น. (เวลาไทย)** และส่งทันทีตอนปิดงานประจำเดือน — หน้านี้ใช้ดูว่าส่งสำเร็จหรือไม่ ไม่ต้องกดอะไรในวันปกติ

[ภาพหน้าจอ: หน้า "Dashboard Sync" แถบสถานะการส่งล่าสุด + ประวัติการส่ง]

**ส่วนบน** — ป้ายใหญ่บอกผลล่าสุด: **ส่งสำเร็จ** · **ตรวจแล้ว ไม่มีการเปลี่ยนแปลง** · **ส่งไม่สำเร็จ** (มี "สาเหตุ" และ "ต้องทำ" บอกให้) · ถ้ายังไม่เคยส่ง จะบอกเวลารอบ Auto Sync แรก · ถ้าขึ้น **"ยังไม่ได้ตั้งค่าการเชื่อมต่อกับ GitHub"** = ผู้ดูแลระบบยังไม่ได้ตั้งค่าที่ฝั่ง Vercel (ไม่ต้องทำในหน้านี้ — แจ้งผู้ดูแลฐานข้อมูล)

**ปุ่ม "ส่งตอนนี้"** — สั่งส่งทันทีโดยไม่รอรอบ 06:00 ใช้เมื่อเพิ่งแก้ข้อมูลแล้วอยากให้ Dashboard เปลี่ยนเลย หรือเมื่อรอบก่อนส่งไม่สำเร็จ
กดแล้วจะขึ้นกล่อง **"ยืนยันส่งข้อมูลขึ้น Dashboard"** บอกว่าส่งอะไร ส่วนไหน และส่งไปที่ไหน → กด **ยืนยันส่ง** (กด **ยกเลิก** หรือ Esc = ไม่ส่ง)
> ⚠ **ยืนยันแล้วผู้บริหารเห็นตัวเลขใหม่บน Dashboard** — อ่านกล่องให้ครบก่อนกด
> ผลที่ขึ้นหลังส่ง: **ส่ง Dashboard สำเร็จ** · **ข้อมูลไม่เปลี่ยน** (ไม่ส่ง เพราะข้อมูลเหมือนเดิม — ถือว่าปกติ) · **มีการส่งอื่นกำลังทำงานอยู่** (รอสักครู่) · **ส่งไม่สำเร็จ — Dashboard ยังแสดงตัวเลขเดิม** (ดูวิธีแก้ในประวัติด้านล่าง)

## งานประจำ 6: ประวัติการแก้ไข (ใครแก้อะไร เมื่อไหร่ ทั้งระบบ)

หน้าที่ใช้: เมนู **ประวัติการแก้ไข** (กลุ่ม "ดูแลระบบ") — **เฉพาะ PM / OM** (ดูอย่างเดียว) · ข้อมูลมาจากบันทึกการแก้ไขที่ระบบเก็บเองทุกครั้ง

[ภาพหน้าจอ: หน้า "ประวัติการแก้ไข" ตัวกรอง + รายการประวัติ (ข้อมูลสมมติ)]

**ส่วนบนของหน้า:**
- ปุ่มเตือน **แก้หลังปิดเดือน (N …)** — กดเพื่อกรองเฉพาะรายการที่แก้ข้อมูลของเดือนที่ปิดไปแล้ว (Dashboard ยังเป็นค่าเดิมจนกว่าจะคำนวณ snapshot ใหม่) · กดซ้ำ (**ยกเลิกกรอง**) เพื่อกลับ
- ป้ายนับ: **แก้ N** · **ลบ N** · **เพิ่ม/ไฟล์ N**
- ข้อความเตือนความเข้าใจ: **"วันที่แก้" ไม่เท่ากับ "เดือนของข้อมูล"** — วันที่แก้ = วันที่มีคนกดบันทึก (คอลัมน์ "เวลา") · เดือนของข้อมูล = เดือนที่ข้อมูลนั้นเป็นของ · ถ้าแก้ข้อมูลของเดือนที่ปิดแล้ว จะขึ้นป้าย "แก้หลังปิดเดือน"

**ตัวกรอง** (จอเล็กพับอยู่หลังปุ่ม **ตัวกรอง**): **ตั้งแต่วันที่** · **ถึงวันที่** · **ใคร** · **เขต** · **สาขา** · **เดือนของข้อมูล** · **ประเภทข้อมูล** · **การกระทำ** (เพิ่ม / แก้ / ลบ) · **เลขที่สัญญา (พิมพ์ให้ตรงตัว)** แล้วกด **ค้น** · **เฉพาะ “แก้หลังปิดเดือน”**
- เลือกได้หลายค่าในแต่ละช่อง (ไม่เลือกเลย = ทั้งหมด) · ตัวกรองที่ใช้อยู่ขึ้นเป็นป้ายใต้ตัวกรอง กด ✕ เอาออกทีละอัน หรือ **ล้างตัวกรองทั้งหมด**
- ช่วงวันที่เลือกได้ไม่เกิน 1 ปี — ถ้ายาวกว่านี้ ระบบตัดวันเริ่มให้เอง

**รายการประวัติ:**
- สลับสิ่งที่แสดง: **เฉพาะการเปลี่ยนแปลง (ค่าเริ่มต้น)** (แก้ / ลบ / ไฟล์ / ปิดเดือน / Port — ไม่รวมการกรอกผลบริการปกติของหัวหน้างาน) หรือ **รวมการกรอกปกติ (จัดเป็นกลุ่ม)**
- สลับมุมมอง: **ตาราง** / **ไทม์ไลน์**
- รายการโหลดทีละ 50 — กด **โหลดเพิ่ม** เพื่อดูรายการที่เก่ากว่า
- ปุ่ม **ส่งออก (CSV สำหรับ Excel)** — ดาวน์โหลดทุกรายการที่ตรงตัวกรองเป็นไฟล์ที่เปิดด้วย Excel ได้

> ⚠ ประวัติและไฟล์ส่งออกอาจมีข้อมูลลูกค้า (PDPA) — เก็บเฉพาะที่จำเป็น ห้ามส่งต่อคนนอกทีม
> ดูประวัติรายสัญญาได้จากปุ่ม **⟲ ประวัติ** ในหน้าเปิดงาน และรายลูกค้าจากแท็บ **ไทม์ไลน์** ในหน้ารายละเอียดลูกค้า (ดูงานประจำ 7–8)

## งานประจำ 7: เปิดงาน/แก้สัญญา และตรวจ Renew ที่ยังไม่ผูก

PM / OM ใช้หน้า **เปิดงานเข้าทะเบียนบริการ** ได้เหมือนแอดมิน (ดูบท `01-Admin-เปิดงาน.md`) และเพิ่มเติม:

- **เห็นทุกสาขา** ไม่จำกัดขอบเขต
- ปุ่ม **"⟲ ประวัติ (N)"** ในแถวสัญญา — ดูประวัติการแก้ไขของสัญญานั้น (หน้าต่าง "ประวัติการแก้ไข · (เลขที่สัญญา)" เรียงจากล่าสุด แสดง เพิ่ม/แก้ไข/ลบ พร้อมตารางที่แก้) — **เฉพาะ PM / OM**
- แก้สัญญาที่ **ปิดแล้ว/ยกเลิกแล้ว** ได้
- **ตรวจ Renew ที่ยังไม่ผูกสัญญาเก่า:** แถว Renew ที่ขึ้น **⚠ ยังไม่ผูก · เชื่อมสัญญาเก่า** → กดเปิดหน้าต่าง **"เชื่อมสัญญาเก่า (Renew)"** → ค้นหา/เลือกสัญญาเก่าของลูกค้ารายเดียวกัน (กรองด้วยเลขที่สัญญา) หรือกด **ไม่มีสัญญาเก่าในระบบ** → ใส่หมายเหตุ (ไม่บังคับ — **ห้ามใส่ข้อมูลส่วนตัวลูกค้า**) → **ยืนยัน ปิดรายการ**
  (ปิดรายการแล้ว ถ้าเจอสัญญาเก่าทีหลัง ยังเชื่อมได้)

## งานประจำ 8: ดูภาพรวมลูกค้ารายคน (ไทม์ไลน์)

ในหน้า **รายละเอียดลูกค้า** แท็บ **ไทม์ไลน์** — "ใครแก้อะไร เมื่อไหร่ ของลูกค้ารายนี้ (เห็นเฉพาะ host)" กรองตาม **สัญญา** และ **เรื่องที่แก้** ได้ · ปุ่ม **ประวัติการแก้ไข** ที่หัวหน้าหน้ารายละเอียดพาไปแท็บนี้

## งานประจำ 9: ทะเบียน · ลูกค้ารอเก็บสถานี · ยกเลิกสัญญา

PM / OM ทำได้ทุกอย่างในหน้าเหล่านี้ ทุกสาขา:

| งาน | ทำที่ไหน | อ่านขั้นตอน |
|---|---|---|
| ดู/ค้นหา/ส่งออกทะเบียน (มีปุ่ม **ประวัติ** ใต้ชื่อลูกค้า เปิดประวัติการแก้ไขของสัญญานั้น — เฉพาะ PM / OM) | เมนู **ทะเบียนลูกค้า/สัญญา** | `01-Admin-เปิดงาน.md` งานประจำ 5 |
| **ยกเลิกสัญญา / เปิดสัญญากลับ** | หน้ารายละเอียดลูกค้า แท็บ **สัญญา** | `01-Admin-เปิดงาน.md` งานประจำ 4 |
| **เก็บแล้ว / ไม่เก็บ / ปิดสัญญา** | เมนู **ลูกค้ารอเก็บสถานี** | `02-หัวหน้างาน.md` งานประจำ 8 |

## ข้อควรระวัง

- **รหัสชั่วคราวส่งให้ผู้ใช้ด้วยตัวเอง** (โทร/แชตส่วนตัว) ห้ามโพสต์ในกลุ่มแชตรวม
- **เปลี่ยนตำแหน่ง = เปลี่ยนสิทธิ์ทันที** — ตรวจชื่อคนและตำแหน่งปลายทางก่อนพิมพ์ "ยืนยันแก้ไข"
- **แก้เกณฑ์ Tier กระทบการคำนวณและตัวเลขที่ส่ง Dashboard** — เลือกเดือนเริ่มใช้ให้ถูก และกรอกเหตุผลให้ชัด
- ต้องมี PM / OM / เจ้าของ ที่ใช้งานอยู่ **อย่างน้อย 1 คน** เสมอ
- ทุกการสร้าง/แก้/ปิดบัญชี และการแก้ตั้งค่า **ลงประวัติการแก้ไขอัตโนมัติ** ย้อนดูได้ที่เมนู **ประวัติการแก้ไข** — แต่ย้อนกลับเองไม่ได้
- **ปุ่มปิดงานประจำเดือน · ส่งตอนนี้ · คำนวณ snapshot ใหม่ = ส่งตัวเลขขึ้น Dashboard จริง** — อ่านกล่องยืนยันให้ครบก่อนกด
- **ปิดสัญญาแล้วเปิดกลับจากหน้าจอไม่ได้** — ต่างจากยกเลิกสัญญาที่เปิดกลับได้ (ตามเงื่อนไข)

## ถามบ่อย

**ผู้ใช้ลืมรหัสผ่าน?**
กด **รีเซ็ตรหัส** ในหน้า "จัดการผู้ใช้" แล้วส่งรหัสชั่วคราวใหม่ให้ (ผู้ใช้รีเซ็ตเองทางอีเมลไม่ได้)

**ผู้ใช้เข้าไม่ได้ ขึ้น "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง"?**
ดูสถานะที่หน้า "จัดการผู้ใช้" ก่อน — ถ้าเป็น **ปิดบัญชี** และต้องการให้ใช้ต่อ ให้กด **เปิดบัญชี** (แล้วพิจารณา **รีเซ็ตรหัส**) · ถ้าบัญชีใช้งานอยู่ แปลว่าพิมพ์ผิดหรือลืมรหัส ให้กด **รีเซ็ตรหัส**

**สร้างตำแหน่ง "เจ้าของ" ให้คนอื่นได้ไหม?**
ไม่ได้ — หน้า "จัดการผู้ใช้" ตั้งตำแหน่งเจ้าของให้คนอื่นไม่ได้

**ลบสัญญาที่มีผลบริการแล้วไม่ได้ ทำยังไง?**
ใช้ **ยกเลิกสัญญา** แทน: หน้ารายละเอียดลูกค้า → แท็บ **สัญญา** → ปุ่ม **ยกเลิกสัญญา** (ขั้นตอนในบท `01-Admin-เปิดงาน.md` งานประจำ 4)
