# 02 — หัวหน้างาน (Supervisor)

> ฉบับใช้อบรม **ศุกร์ 27 พ.ย. 2026** · ปรับล่าสุด 20 พ.ย. 2026 · ชื่อปุ่ม/เมนูตรวจกับหน้าจอจริงแล้ว · ชื่อลูกค้า เลขที่สัญญา เลขสถานีในคู่มือเป็น **ข้อมูลสมมติ**

## ทำอะไรได้บ้าง

หัวหน้างานคือคนที่ **กรอกผลบริการประจำเดือน** แทนทีมหน้างาน (ทีมบริการหน้างานไม่มีบัญชี — ส่งสรุปงานให้หัวหน้างานกรอกแทน)

| ทำได้ | ทำไม่ได้ |
|---|---|
| กรอก/แก้/ลบผลบริการประจำเดือน (รวมกล่อง AG) | เพิ่ม/แก้ลูกค้าและสัญญา (หน้าเปิดงานเป็นของแอดมิน) |
| กรอกงานกล่อง AG นอกรอบประจำเดือน | จัดการผู้ใช้ · ตั้งค่า (เป็นของ PM / OM) |
| ตัดสินเรื่อง **ตกบริการ** ("ไม่ชดเชย" / บันทึกบริการชดเชย) | บันทึกบริการชดเชยที่ **เลยเพดานชดเชยแล้ว** (ต้องให้ PM / OM) |
| ดูรายละเอียดลูกค้า · แก้ข้อมูลติดต่อลูกค้า | ดูแท็บ "ไทม์ไลน์" / ประวัติการแก้ไข (เฉพาะ PM / OM) |
| ดู Dashboard สรุปมูลค่าทั้งหมด | |

เมนูที่เห็น: **สถานะทะเบียนบริการ · ลงข้อมูลทำบริการประจำเดือน · กล่อง AG นอกรอบประจำเดือน · ลูกค้ารอเก็บสถานี · ทะเบียนลูกค้า/สัญญา · สรุปงานบริการรายเดือน · Dashboard สรุปมูลค่าทั้งหมด · ส่งข้อมูล และสรุปงานประจำเดือน**

> ⏳ รอหน้าจริง · เมนูที่ **ยังเป็นหน้าโครง** ตอนนี้มี 2 เมนู: **ทะเบียนลูกค้า/สัญญา** · **ลูกค้ารอเก็บสถานี** — ดูหัวข้อ "ส่วนที่ยังรอหน้าจริง" ท้ายบท · เมนูอื่น (รวม **สรุปงานบริการรายเดือน** และ **ส่งข้อมูล และสรุปงานประจำเดือน**) ใช้งานได้แล้ว

## ภาพรวมงานของเดือน

```
สถานะทะเบียนบริการ (ดูว่าเหลืออะไร)
        ↓
ลงข้อมูลทำบริการประจำเดือน (กรอกทีละราย)  +  กล่อง AG นอกรอบ (ถ้ามี)
        ↓
ตัดสินเรื่องตกบริการที่ค้าง (ชดเชย / ไม่ชดเชย)
        ↓
ปิดเดือน  (เมนู "ส่งข้อมูล และสรุปงานประจำเดือน" · งานประจำ 7)
```

## งานประจำ 1: เช็กสถานะประจำเดือน

หน้าที่ใช้: เมนู **สถานะทะเบียนบริการ** (หน้าแรกของหัวหน้างาน)

[ภาพหน้าจอ: หน้า "สถานะทะเบียนบริการ" แถบความคืบหน้า + การ์ดสรุป 3 ใบ]

หน้านี้บอกว่า "งานที่ต้องทำของเดือน" เหลืออะไร:

- **สถานะงานกรอกผล · (เดือน)** — "กรอกผลแล้ว X / Y ราย" และ "เหลือยังไม่กรอก N ราย" (ตัวเลขแดง = ยังเหลือ)
  หน้านี้แสดง **เดือนที่ยังไม่ปิดเก่าสุด** — ปิดเดือนแล้วหน้านี้เลื่อนไปเดือนถัดไปเอง
- การ์ด **เรื่องตกบริการรอตัดสิน** · **ลูกค้ารอเก็บสถานี** · **กล่องเหยื่อรอถอด**
- รายการ **ยังไม่มีข้อมูล (ยังไม่กรอก)** — แสดง 10 รายแรก (เรียงตามชื่อ) กดลิงก์ **เปิดหน้ากรอกผลบริการ →** เพื่อไปกรอก
- รายการ **กล่องเหยื่อรอถอด** — จุดกล่อง AG ที่พบปลวกตายแล้ว รอถอด · ลิงก์ **ดูกล่องติดตามผลทั้งหมด →**
- ถ้าขึ้นแถบ **"ยังปิดงานเดือน … ไม่เสร็จ"** แปลว่าเข้าเดือนใหม่แล้วแต่เดือนก่อนยังไม่ปิด ตัวเลือกในแถบ: **ไปกรอกข้อมูลต่อ** · **ไปหน้าปิดเดือน** · **ไว้ทีหลัง**

## งานประจำ 2: กรอกผลบริการประจำเดือน (ทีละราย)

หน้าที่ใช้: เมนู **ลงข้อมูลทำบริการประจำเดือน**

หลักคิดของหน้านี้: **ตั้งต้นว่าทุกจุดปกติ — กรอกเฉพาะที่พบปลวก เปลี่ยนไม้ งานซ่อม/ฝังเพิ่ม** (และงานกล่องเหยื่อ AG กรอกในฟอร์มเดียวกัน)

[ภาพหน้าจอ: หน้า "ลงข้อมูลทำบริการประจำเดือน" รายชื่อลูกค้าซ้าย + ฟอร์มกรอกขวา]

### ส่วนซ้าย: เลือกลูกค้า

1. เลือก **เขต** · **สาขา** · **เดือน** (ตัวกรองบนสุดของรายชื่อ "ลูกค้า")
2. หรือพิมพ์ในช่อง **"พิมพ์ชื่อลูกค้า หรือเลขที่สัญญา"** เพื่อค้นหา (ถ้าพิมพ์ผิดนิดหน่อย จอจะถาม "ไม่พบตรงตัว หมายถึงรายนี้ไหม")
3. สลับมุมมอง **ยังไม่กรอก** / **กรอกแล้ว** (ตัวเลือกด้านบนรายชื่อ) — ตัวอย่าง "กรอกแล้ว 12 / 40" บอกความคืบหน้า
4. กดชื่อลูกค้า → ฟอร์มกรอกขึ้นทางขวา
   - รายชื่อแสดงเฉพาะสัญญาที่ **อยู่ในช่วงบริการของเดือนที่เลือก**
   - แสดงได้สูงสุด 1,000 ราย — เลือกสาขาเพื่อดูครบ

### ส่วนขวา: ฟอร์มกรอก

หัวฟอร์มบอก "รายที่ N จาก M" + เลขที่สัญญา + ป้าย New/Renew เดือนนี้ · ถ้ารายนี้กรอกแล้วจะมีป้าย **"กรอกแล้ว · บันทึกซ้ำเพื่อแก้ไข"**

**(ก) ลูกค้าใหม่ครั้งแรก — ต้องระบุจำนวนสถานี**
ถ้าขึ้นกล่อง **"ระบุจำนวนสถานีครั้งแรก"** (สัญญาใหม่ยังไม่มีจำนวนสถานี) ให้ทำก่อนกรอกผล:
- ลูกค้าใหม่: ใส่ **IG (จำนวน)** และ **IC (จำนวน)** ที่ติดตั้งจริง (บังคับครั้งแรกครั้งเดียว) ระบบสร้างเลขสถานี 1..n ให้เอง
- สัญญาต่ออายุ (Renew): ระบบเสนอ **ย้ายสถานีที่ยังใช้งานจากสัญญาเก่า** มาให้ (ใช้เลขเดิม · รอบกล่อง AG นับต่อ) — กดติ๊กออกสถานีที่ไม่ย้ายได้ (**ย้ายทั้งหมด** / **ไม่ย้ายเลย** / **เลือกรายสถานี**) และเพิ่มสถานีใหม่ที่ช่อง **เพิ่ม IG ใหม่ (จำนวน)** / **เพิ่ม IC ใหม่ (จำนวน)**
- ทำครั้งเดียวต่อสัญญา

**(ข) ข้อมูลการเข้า**
1. **ทีมที่เข้า** — กดเลือกทีม (เลือกได้หลายทีม แล้วกด **เสร็จ**) · ช่องจะเติมจากครั้งก่อนให้ ถ้ายังไม่เคยเข้าให้เลือกเอง
2. **วันที่เข้า** — วันที่เข้าบริการจริง
3. **เวลาเข้า (24 ชม.)** และ **เวลาออก (24 ชม.)** — พิมพ์เช่น `09:30` และ `14:45` (*ตัวอย่าง*) · เวลาออกต้องหลังเวลาเข้า
4. **เวลาทำงานจริง (คำนวณเอง)** — ระบบคำนวณให้ ไม่ต้องกรอก
5. **ตรวจภายใน** (ช่องติ๊ก — ขึ้นเฉพาะการเข้ารอบประจำเดือน) — ติ๊กเมื่อการเข้าครั้งนี้มีการตรวจภายในอาคาร · ตัวเลขไปแสดงในการ์ด "ตรวจภายใน" ของหน้า **สรุปงานบริการรายเดือน** (งานประจำ 6)

**(ค) ถ้าทุกจุดปกติ — กดปุ่มเดียว**
กดปุ่มใหญ่ **"IG / IC ปกติทั้งหมด"** (คำอธิบาย: ไม่พบปลวก ไม่เปลี่ยนไม้ ไม่มีงานซ่อม · ไม่รวมกล่อง AG) ปุ่มจะเปลี่ยนเป็น "กดแล้ว ✓"
> ถ้ามีรายการพบปลวก/เปลี่ยนไม้/งานซ่อมอยู่แล้ว จะกดไม่ได้ จอเตือน "ลบออกก่อนจึงกด “ปกติทั้งหมด” ได้"

[ภาพหน้าจอ: หน้ากรอกผลบริการ ปุ่ม "IG / IC ปกติทั้งหมด"]

**(ง) ถ้าพบปลวก — หัวข้อ "พบปลวก"**
1. กด **เพิ่มจุดที่พบปลวก**
2. เลือก **สถานี** (IG หรือ IC) + พิมพ์ **เลขสถานี**
3. เลือก **ชนิดปลวก**:
   - **ปลวกใต้ดิน** = ใส่เหยื่อ → เลือก **ปริมาณเหยื่อ** (0 / 50 / 100 / 150 / 200 ก. หรือ "มากกว่า 200 (พิมพ์เอง)" ต้องหาร 50 ลงตัว เช่น 250, 300) และ **การกินเหยื่อ** (ไม่บังคับ)
   - **ปลวกสวน** = เคมีผง → กรอก **เคมีผง (จุด)** จำนวนจุด (ระบบคูณ 0.3 ก./จุดให้)
4. จุดที่เพิ่มผิด กด **ลบ**
5. ยอดสรุปขึ้นให้ที่หัวข้อ เช่น "ปลวกใต้ดิน N จุด" "ปลวกสวน N จุด" "เหยื่อรวม N ก."

**(จ) ถ้าเปลี่ยนไม้ล่อ — หัวข้อ "เปลี่ยนไม้ล่อ"**
1. กด **เพิ่มสถานีที่เปลี่ยนไม้**
2. เลือกชนิดสถานี + พิมพ์เลขสถานี **ได้หลายเลขในแถวเดียว** เช่น `3, 5, 8-12` (ตัวอย่าง)
3. จำนวนไม้ระบบคำนวณเอง (IG = 2 ชิ้น · IC = 1 ชิ้น ต่อสถานี) ป้าย **อัตโนมัติ**

**(ฉ) งานซ่อม / ฝังเพิ่มสถานี — หัวข้อ "งานซ่อม และ ฝังเพิ่มสถานี"**
1. กด **เพิ่มงานซ่อม** (หรือ **ฝังสถานีเพิ่ม**)
2. เลือก **ประเภทงาน**: เปลี่ยนฝาสถานี · สถานีหาย · ถอนสถานีออก · อื่นๆ (กลุ่ม "งานซ่อม") หรือ ฝังสถานีใหม่ (กลุ่ม "เพิ่มสถานี")
3. พิมพ์เลขสถานี (หลายเลขได้ เช่น `3, 5, 8-12` · ฝังใหม่เช่น `81-85`)
4. **"สถานีหาย" และ "อื่นๆ" ต้องใส่รายละเอียด** (ช่อง "รายละเอียดงาน")
5. ระบบแสดง "จำนวนสถานีลูกค้า (หลังบันทึก): IG … → …" ให้เห็นผล

**(ช) งานกล่องเหยื่อ AG ที่ทำพร้อมรอบนี้ — หัวข้อ "กล่องเหยื่อ AG"**
ดูหัวข้อ "งานประจำ 4" ด้านล่าง (ใช้ช่องกรอกแบบเดียวกัน)

### บันทึก

- ถ้ายังกรอกไม่ครบ จอขึ้นกรอบ **"บันทึกไม่ได้ — ยังขาด"** (กดที่รายการเพื่อเลื่อนไปช่องที่ขาด) เช่น "ทีมที่เข้า (เลือกอย่างน้อย 1 ทีม)" · "เวลาเข้า" · "เวลาออกต้องหลังเวลาเข้า" · "พบปลวก: N แถวยังไม่ครบ/ไม่ถูกต้อง"
- ครบแล้วกด **บันทึก + รายถัดไป** → จอขึ้น "บันทึกผล “…” แล้ว" และกระโดดไปรายถัดไปที่ยังไม่กรอกเอง
- ปุ่มอื่น: **ข้าม** (ข้ามไปรายอื่นก่อน) · **←** (รายก่อนหน้า)
- ถ้ากด ← / ข้าม / เลือกรายอื่นตอนมีข้อมูลค้างยังไม่บันทึก จอถาม **"ออกจากรายนี้โดยไม่บันทึก?"** → **กลับไปกรอกต่อ** หรือ **ออกโดยไม่บันทึก**
- ทำครบทุกราย จอขึ้น **"✓ กรอกครบทุกรายแล้ว"**

### เข้าบริการหลายครั้งในเดือนเดียว / แก้ผลที่กรอกแล้ว

- รายที่กรอกแล้ว กดชื่อซ้ำเพื่อ **แก้** แล้วกดบันทึกใหม่ได้ (สลับมุมมองเป็น **กรอกแล้ว** เพื่อหารายนั้น)
- ถ้าเข้าหลายครั้งในเดือน: แถบ **"การเข้าในเดือนนี้:"** แสดง "ครั้งที่ 1 · วัน/เดือน" … กดสลับดู/แก้ได้ · กด **+ การเข้าใหม่** เพื่อเพิ่มครั้งใหม่
- ลบการเข้า: กด **ลบการเข้านี้** → ยืนยัน (ลบผลตรวจ ทีม และงานซ่อมของครั้งนี้ทั้งหมด · ย้อนกลับไม่ได้ แต่ประวัติการแก้อยู่ในประวัติการแก้ไข)

> เดือนที่ปิดแล้ว **ไม่ล็อกข้อมูล** — หัวหน้างานยังแก้ผลย้อนหลังได้ (ทุกการแก้ลงประวัติการแก้ไขอัตโนมัติ)
> ⚠ สัญญาที่ **ปิดหรือยกเลิกแล้ว** — จอเตือน "เฉพาะ Host เท่านั้นที่แก้ได้ — บัญชีอื่นบันทึกไม่ได้"

## งานประจำ 3: ตัดสินเรื่องตกบริการ

หน้าที่ใช้: **สถานะทะเบียนบริการ** → กล่อง **"เรื่องตกบริการรอตัดสิน"** (หรือแท็บ **ประวัติทำบริการ** ในหน้ารายละเอียดลูกค้า → ส่วน **"เดือนที่ตกบริการ"**)

"ตกบริการ" = เดือนที่ลูกค้าอยู่ในสัญญาแต่ไม่มีการเข้าบริการ แต่ละรายการบอก "ชดเชยได้ถึง (เดือน)" — เรียกว่า **เพดานชดเชย**

[ภาพหน้าจอ: กล่อง "เรื่องตกบริการรอตัดสิน" ปุ่ม "บันทึกบริการชดเชย" และ "ไม่ชดเชย"]

มี 2 ทางให้เลือก:

**ทาง ก: ไปบริการชดเชยแล้ว → "บันทึกบริการชดเชย"**
กดปุ่มนี้ ระบบพาไปหน้า **ลงข้อมูลทำบริการประจำเดือน** (กรองสาขาให้แล้ว)
- เลยเพดานชดเชยแล้ว: หัวหน้างานบันทึกไม่ได้ จอบอก "หัวหน้างานบันทึกบริการชดเชยไม่ได้ (ต้องให้ Host)" · PM / OM บันทึกได้เป็นกรณีพิเศษ (ปุ่มขึ้น "(เกินเพดาน)") · แต่ยังกด **ไม่ชดเชย** เพื่อปิดเรื่องได้
> ⚠ **ข้อจำกัดตอนนี้ (ตรวจกับระบบ 20 พ.ย.):** ปุ่ม **บันทึกบริการชดเชย** พาไปหน้าลงข้อมูลได้ แต่ในฟอร์มกรอกผลตอนนี้ **ยังไม่มีช่องระบุว่าเป็นการเข้าชดเชยของเดือนไหน** — กรอกเป็นการเข้าของเดือนที่ไปทำจริงไปก่อน แล้วแจ้ง PM / OM ถ้าต้องการให้เชื่อมกับเดือนที่ตกบริการ

**ทาง ข: ลูกค้ายินยอมไม่ต้องชดเชย → "ไม่ชดเชย"**
1. กดปุ่ม **ไม่ชดเชย** ที่แถวของรายนั้น → หน้าต่าง **"ไม่ชดเชย (เดือน)"**
2. ช่อง **เหตุผล (บังคับ)** — เช่น "ลูกค้ายินยอม ปิดอาคารทั้งเดือน" (*ตัวอย่างสมมติ*)
3. ช่อง **หลักฐาน (ไม่บังคับ · PDF / PNG / JPG ไม่เกิน 5 MB)** — แนบถ้ามี
4. กด **ไม่ชดเชย** → ระบบถามอีกรอบ "ปิดเรื่องเดือนนี้โดยไม่ชดเชย?" → กด **ยืนยัน ไม่ชดเชย** (หรือ **กลับไปแก้**)
5. เดือนนั้นยังนับเป็นตกบริการในประวัติ แต่ปิดเรื่องไม่ต้องตามต่อ

**กดผิด ปิดเรื่องไปแล้ว?** — เปิดหัวข้อ **"เรื่องที่ปิดแล้ว N ราย (ไม่ชดเชย · ชดเชยแล้ว)"** แล้วกด **เปิดเรื่องกลับ** → ยืนยัน (**ยืนยัน เปิดเรื่องกลับ**) เรื่องจะกลับเป็น "รอตัดสิน" · ลงประวัติการแก้ไขอัตโนมัติ

## งานประจำ 4: กล่อง AG

กล่อง AG ไม่เหมือน IG/IC — มีขั้นตอนติดตามเป็นรอบ:

**ติดกล่องใหม่ (S) → ติดตามผล F1, F2, … แยกแต่ละจุด → รอถอด (พบปลวกตาย) → ถอดแล้ว (ยืนยันว่าตายจริง จบปัญหา)**

เลขรอบ F **ระบบนับให้เอง** ไม่ต้องกรอก (ป้าย **อัตโนมัติ**) และนับแยกตามแต่ละจุด/สถานี

### ทำพร้อมรอบบริการประจำเดือน
กรอกในหัวข้อ **"กล่องเหยื่อ AG"** ของฟอร์ม **ลงข้อมูลทำบริการประจำเดือน**

### ทำนอกรอบ (ไม่ได้เข้าพร้อมรอบประจำเดือน)
หน้าที่ใช้: เมนู **กล่อง AG นอกรอบประจำเดือน**

1. เลือกลูกค้าทางซ้าย (มีมุมมอง **มีกล่องค้างติดตาม** / **ทุกราย**)
2. ฟอร์มหัวข้อ **"งานกล่องนอกรอบประจำเดือน"** — ใส่ **ทีมที่เข้า** · **วันที่เข้าจริง (ตามใบงาน)** (ระบบใส่วันที่บันทึกให้เอง ปรับได้) · เวลาเข้า/ออก
3. กรอกงานกล่องตามข้อ "แต่ละจุดของกล่อง" ด้านล่าง
4. กด **บันทึกงานกล่อง** (ถ้าจะกรอกอีกวัน: **บันทึกแล้วเพิ่มอีกวัน**) · แก้การเข้าที่เคยบันทึก: กด **แก้** ในรายการ "การเข้านอกรอบที่บันทึกแล้ว" → **บันทึกการแก้ไข** (หรือ **เลิกแก้**) · ลบ: **ลบการเข้านี้**
- กรอกเรียงจากวันที่เก่าไปใหม่
- ถ้าสัญญานั้นยังไม่ระบุจำนวนสถานี จอบอก "ไปที่หน้า “ลงข้อมูลทำบริการประจำเดือน” ตั้งจำนวนสถานี IG/IC ของสัญญานี้ก่อน"

### แต่ละจุดของกล่อง
- **+ ติดกล่องใหม่ (S)** — ติดตั้งใหม่ ใส่ **เหยื่อที่ใส่** และ **ป้ายจุด** (ไม่บังคับ เช่น ห้องนอน) · ไม่นับเป็นรอบตรวจ ครั้งถัดไปเป็น F1
- จุดที่ติดไว้แล้ว: ใส่ **ปริมาณเหยื่อที่ใช้** · **การกินเหยื่อ** (ไม่บังคับ) · **สัดส่วนปลวกที่พบ** (ไม่พบปลวก · งาน>ทหาร · ทหาร>งาน · ทหาร · ทหาร+สืบพันธุ์สำรอง · สืบพันธุ์สำรอง · ปลวกตาย) · **สถานะจุดนี้**:
  - **ติดตามผล** = ยังตรวจต่อ
  - **รอถอด (ปลวกตาย)** = พบปลวกตายแล้ว รอถอดกล่อง
  - **ถอดแล้ว (จบปัญหา)** = ยืนยันว่าตายจริงและถอดกล่องออกแล้ว — จบงานจุดนี้ **เปลี่ยนสถานะอีกไม่ได้**
- ทีมเข้ามาแต่ไม่ได้ตรวจจุดไหน ติ๊ก **ไม่ได้ตรวจจุดนี้** (ไม่ต้องกรอกผล และไม่นับเป็นรอบตรวจ) · ไม่ได้ตรวจกล่อง AG เลยสักจุดให้ติ๊กทางลัด **"รอบนี้ไม่ได้ตรวจกล่อง AG เลย (ข้ามทุกจุด)"**
- ตั้งชื่อจุดภายหลัง: กดไอคอนดินสอ ✎ ข้างชื่อจุด → **บันทึกชื่อจุด** (บันทึกทันที ไม่ต้องบันทึกการเข้า) · เว้นว่างแล้วบันทึก = ลบชื่อจุด

## งานประจำ 5: ดูรายละเอียดลูกค้า

เปิดจากลิงก์ชื่อลูกค้าในหน้าต่างๆ — มี 6 แท็บ: **ภาพรวม · สัญญา · สถานี · ประวัติทำบริการ · ไฟล์แนบ · ไทม์ไลน์** (ไทม์ไลน์ดูได้เฉพาะ PM / OM)

หัวหน้างานใช้บ่อย:
- ปุ่มลัดบนหัวหน้า: **ลงข้อมูลทำบริการประจำเดือน** · **กล่อง AG นอกรอบประจำเดือน**
- แท็บ **สถานี** — ดูสถานีของลูกค้า กรองได้ (ชนิด / สถานะ / ค้นรหัสสถานี) · มุมมอง **ต้องดู** = จุดที่ต้องตามต่อ
- แท็บ **ประวัติทำบริการ** — ทุกครั้งที่เข้า + เดือนที่ตกบริการ + ตัดสินเรื่องตกบริการได้ที่นี่
- แผงข้อมูลลูกค้า — แก้ **ผู้ติดต่อ · โทร · หมายเหตุ** ได้ (กดดินสอ → บันทึก)
- แท็บ **ไฟล์แนบ** — **ดู** / **ดาวน์โหลด** ไฟล์สัญญา
- แก้สัญญา/ข้อมูลหลักของลูกค้าไม่ได้ (จอแสดง "ดูอย่างเดียว") — แจ้งแอดมิน

## งานประจำ 6: ดูสรุปงานบริการรายเดือน

หน้าที่ใช้: เมนู **สรุปงานบริการรายเดือน** (กลุ่ม "ทะเบียนและสรุป") — หัวหน้างาน แอดมิน และ PM / OM เปิดได้ · **ดูอย่างเดียว ไม่มีอะไรให้กรอก** · ไม่มีชื่อลูกค้าในหน้านี้

หน้านี้ตอบคำถามว่า "เดือนนี้ใช้วัสดุไปเท่าไหร่ และแต่ละทีมทำงานหนักแค่ไหน" — ตัวเลขมาจากผลบริการที่หัวหน้างานกรอกไว้ ถ้ายังกรอกไม่ครบ ตัวเลขจะต่ำกว่าจริง

[ภาพหน้าจอ: หน้า "สรุปงานบริการรายเดือน" แถบเลือกเดือน/สาขา + แท็บ "การใช้อุปกรณ์" (ข้อมูลสมมติ)]

**เลือกข้อมูลที่จะดู:** เลือก **เดือน** และ **สาขา** (หรือ "ทุกสาขา") แล้วกดปุ่ม **ดูข้อมูล** — ต้องกดปุ่มนี้ทุกครั้งที่เปลี่ยนเดือน/สาขา ตัวเลขจึงเปลี่ยน

มี 2 แท็บ (กดสลับด้านบนของหน้า):

**แท็บ "การใช้อุปกรณ์"** — การใช้วัสดุ
- การ์ดรวม: **NEMESIS (เหยื่อ) ที่ใช้** · **เคมีผง (ปลวกสวน)** · **ไม้ล่อที่เปลี่ยน**
- **สรุปตามประเภทงาน** — แยก **บริการประจำเดือน** · **ชดเชย (ส่วนหนึ่งของประจำเดือน)** · **แก้ไขปัญหา**
- **กราฟเปรียบเทียบ** — วัสดุ 4 กลุ่ม (บริการประจำเดือน · แก้ไขปัญหา · ลูกค้า New · ลูกค้า Renew)
- **ตรวจภายใน** — จำนวนครั้งและจำนวนสัญญาที่ติ๊ก "ตรวจภายใน" ในเดือนนั้น แยกสาขา/ทีม (ถ้ายังไม่มี จะขึ้น "ยังไม่มีการตรวจภายใน")
- **มุมมอง 1 · ตามประเภทงาน** และ **มุมมอง 2 · ตามประเภทลูกค้า (New / Renew)** — ตารางละเอียด
- **ตารางรวมทุกวัสดุ แยกสาขา** — มีช่อง "กล่อง AG ที่ตรวจ" และ "ก./กล่อง AG"

**แท็บ "สรุปรายทีม"** — ภาระงานของแต่ละทีม
- ตารางบอก **ทีม · ประเภท · เข้า (ครั้ง) · เวลารวม (ชม.) · จำนวนคน · ชม./คน เทียบเกณฑ์** — ทีมที่ชั่วโมงต่อคนเกินเกณฑ์ขึ้นแถบเหลือง "มีทีมเกินเกณฑ์ภาระงาน" และป้าย "เกินเกณฑ์"
- ถ้าช่องจำนวนคนขึ้น "ยังไม่ตั้ง" = ยังไม่ได้ใส่จำนวนคนภาคสนามของทีมนั้น ให้แจ้ง PM / OM ไปตั้งที่เมนู **ตั้งค่า** แท็บ **ทีม**

**ควรรู้:**
- ถ้าขึ้น "เดือนนี้ยังไม่มีการบันทึกบริการ" = ยังไม่มีใครกรอกผลของเดือนนั้น (ไม่ใช่ระบบเสีย)
- ถ้าขึ้นแถบเหลือง **"ข้อมูลมากเกินกว่าจะโหลดครบ"** → เลือกสาขาให้แคบลง
- งานซ่อมที่ทำในรอบปกติถูกนับเป็น "บริการประจำเดือน"

## งานประจำ 7: ปิดเดือน (ส่งข้อมูล และสรุปงานประจำเดือน)

หน้าที่ใช้: เมนู **ส่งข้อมูล และสรุปงานประจำเดือน** (กลุ่ม "ดูแลระบบ" — หัวหน้างานเห็นเฉพาะเมนูนี้ในกลุ่มนั้น)

"ปิดเดือน" = ยืนยันว่าตัวเลขบริการของเดือนนั้นนิ่งแล้ว และ **ส่งตัวเลขขึ้น AGA Bait Dashboard** ให้ทันที

> ⚠ **กดปิดแล้วตัวเลขขึ้น Dashboard จริงทันที** — ตรวจให้แน่ใจก่อนกดปุ่มสุดท้าย · ในอบรมให้ดูตามผู้สอน อย่ากดปิดเดือนจริงเอง

[ภาพหน้าจอ: หน้า "ส่งข้อมูล และสรุปงานประจำเดือน" รายการเดือนซ้าย + การ์ด ส่วนกลาง / ต่างจังหวัด ขวา]

**ส่วนบนของหน้า:** การ์ด **ส่ง Dashboard สำเร็จล่าสุด** (วันเวลา) และกล่อง **สถานะส่ง Dashboard**

**ซ้าย: "รายการเดือน"** — กดเลือกเดือน แต่ละเดือนมีป้าย **กลาง · …** และ **ตจว. · …** บอกสถานะ: **รอปิด** · **ปิดแล้ว** · **ยังไม่จบ** (เดือนยังไม่สิ้นสุด ปิดได้ตั้งแต่เดือนถัดไป) · เดือนที่ปิดครบทั้งสองส่วนมีข้อความ "อัพเดทข้อมูลครบทุกสาขา" · ป้าย **แก้หลังปิด N** = มีการแก้ข้อมูลหลังปิดแล้วกี่ครั้ง

**ขวา:** การ์ด 2 ใบ ปิดแยกกัน
- **ส่วนกลาง 24 สาขา** — ผู้ปิดได้: PM / OM หรือหัวหน้างาน
- **ต่างจังหวัด 19 สาขา** — ผู้ปิดได้: **PM / OM เท่านั้น** (หัวหน้างานจะเห็นปุ่มเป็น "เฉพาะ OM/PM ปิดได้")

### ปิดส่วนกลาง (3 ขั้น)

1. กดปุ่ม **ปิดส่วนกลาง** ที่การ์ด แล้วทำทีละขั้น (แถบ 3 ขั้นด้านบน กดย้อนไปมาได้):
   - **ขั้น 1 ตรวจความครบ** — ระบบดูว่า 24 สาขาบันทึกบริการครบหรือยัง · ขึ้น "ทุกสาขาส่วนกลางบันทึกบริการครบแล้ว" = พร้อมปิด · ถ้าไม่ครบจะมีตารางบอก **สาขา** และ **ค้าง (ราย)** → กด **ถัดไป: ทบทวนตกบริการ →**
   - **ขั้น 2 ทบทวนตกบริการ** — รายชื่อสัญญาที่ตกบริการรอตัดสิน (กด **แสดงทั้งหมด N ราย** ถ้ามีเยอะ) · ให้ตัดสินเรื่องที่ค้างตามงานประจำ 3 ก่อน → กด **ถัดไป: ยืนยันปิด →**
   - **ขั้น 3 ยืนยันปิด** — อ่านคำเตือนในกรอบแดง/เหลือง ("การปิดส่วนกลางจะส่ง Dashboard ทันที" · "ปิดส่วนกลางมีผลกับทุกสาขาส่วนกลาง (24 สาขา) ไม่ใช่เฉพาะทีมของคุณ")
2. ช่อง **พิมพ์ … เพื่อยืนยันการปิดเดือน** — พิมพ์รหัสเดือนที่จอบอกให้ตรง (รูปแบบ ตัวย่อเดือนภาษาอังกฤษ.ปี 2 หลัก เช่น `OCT.26` ← *ตัวอย่าง*)
3. กดปุ่ม **ปิดส่วนกลาง (เดือน ปี) และส่ง Dashboard**
4. ผลที่ขึ้นด้านบน: "ปิดส่วนกลาง … เรียบร้อย · ส่ง Dashboard สำเร็จ" (หรือ "ข้อมูลไม่เปลี่ยน ไม่ต้องส่ง Dashboard")

**ถ้ามีสาขาบันทึกไม่ครบตอนกดปิด:** ขึ้น **"ยังมีสาขาที่บันทึกบริการไม่ครบ"** พร้อมรายชื่อสาขาและจำนวนที่ค้าง
- **หัวหน้างาน** ปิดข้ามไม่ได้ ("หัวหน้างานปิดข้ามไม่ได้ — กรอกให้ครบ หรือแจ้ง OM/PM ให้ปิดข้ามพร้อมเหตุผล")
- **PM / OM** ใส่ **เหตุผลที่ปิดข้าม (5–500 ตัวอักษร)** แล้วกดปุ่มปิดอีกครั้งได้

### ปิดต่างจังหวัด (PM / OM)

กดปุ่ม **ปิดต่างจังหวัด** → ยืนยันขั้นเดียว (พิมพ์รหัสเดือนแล้วกดปุ่ม **ปิดต่างจังหวัด (เดือน ปี) และส่ง Dashboard**) · ควรลงข้อมูลที่เมนู **ลงข้อมูล Port ต่างจังหวัด** ให้ครบก่อน · ถ้ามีสาขาที่ยังใช้ "ค่ายกมาจากเดือนก่อน" จะมีช่องติ๊ก **รับทราบว่า … สาขา ยังใช้ค่ายกมา …** ให้ติ๊กก่อนปิด

### เดือนที่ปิดแล้ว

กดปุ่ม **ดูรายละเอียด** ที่การ์ด จะเห็น **ปิดเมื่อ** / **ปิดโดย**
- ข้อความสีฟ้า **"เดือนนี้แก้ข้อมูลย้อนหลังได้ตามปกติ"** — หัวหน้างานและ PM / OM ยังแก้ผลบริการเดือนนี้ได้ ไม่ต้องปลดล็อก · ทุกการแก้ลงประวัติการแก้ไข
- **ตัวเลขบน Dashboard จะไม่เปลี่ยนเอง** จนกว่า PM / OM กดปุ่ม **คำนวณ snapshot ใหม่ + ส่ง Dashboard** (หัวหน้างานจะเห็นข้อความ "การคำนวณ snapshot ใหม่ทำได้เฉพาะ OM/PM")
- หัวข้อ **แก้หลังปิด** — รายการว่าใครแก้อะไรหลังปิดเดือน
- ถ้าขึ้น **"รอบส่ง Dashboard ล่าสุดไม่สำเร็จ"** = เดือนปิดแล้ว แต่ Dashboard อาจยังเป็นค่าเดิม ระบบจะลองส่งใหม่ทุกวัน 06:00 น. หรือให้ PM / OM กดส่งเอง (ดูบท `03-PM-OM.md` หัวข้อ Dashboard Sync)

## ส่วนที่ยังรอหน้าจริง

> ⏳ รอหน้าจริง · **ทะเบียนลูกค้า/สัญญา** — ยังเป็นหน้าโครง ณ วันที่ปรับคู่มือนี้ · ส่วนนี้จะเติมเมื่อหน้าจริงเสร็จ
> (ใช้ดูรายชื่อลูกค้า/สัญญาแล้วกดเข้าไปดูรายละเอียดรายคน · ระหว่างนี้เปิดหน้ารายละเอียดลูกค้าได้จากลิงก์ชื่อลูกค้าในหน้าอื่น เช่น หน้า "เปิดงานเข้าทะเบียนบริการ")
>
> ⏳ รอหน้าจริง · **ลูกค้ารอเก็บสถานี** — ยังเป็นหน้าโครง ณ วันที่ปรับคู่มือนี้ · ส่วนนี้จะเติมเมื่อหน้าจริงเสร็จ
> (ใช้ติดตามลูกค้าที่หมดสัญญาและต้องไปเก็บสถานีคืน · การ์ด "ลูกค้ารอเก็บสถานี" ในหน้า "สถานะทะเบียนบริการ" มีตัวเลขสรุปให้ดูได้)

## ข้อควรระวัง

- **กรอกแล้วต้องกดบันทึกทุกราย** ข้อมูลที่ค้างไม่บันทึกจะหายถ้าออกจากรายนั้น
- เลือก **เดือน / สาขา** ให้ตรงก่อนเริ่มกรอก — รายชื่อเปลี่ยนตามตัวกรอง
- **เลขสถานีพิมพ์ได้หลายเลข** คั่นด้วยจุลภาค (`3, 5, 8-12`) — ดูให้ดีว่าไม่ซ้ำกับจุดอื่น
- **ถอดแล้ว (จบปัญหา)** ของกล่อง AG **เปลี่ยนกลับไม่ได้** — ตรวจให้แน่ใจว่าปลวกตายจริงและถอดกล่องแล้ว (ยกเว้นเข้าบริการครั้งที่ถอดนั้นเอง ที่เปลี่ยนกลับได้ถ้ายังไม่มีการเข้าครั้งหลัง และยังไม่ Renew)
- **ห้ามใส่ข้อมูลส่วนตัวลูกค้าในช่องที่คนอื่นอ่านได้** เกินที่จำเป็น

## ถามบ่อย

**รายชื่อลูกค้าที่ควรกรอกไม่ขึ้น?**
เช็ก **เขต / สาขา / เดือน** ที่ตัวกรอง · รายชื่อแสดงเฉพาะสัญญาที่อยู่ในช่วงบริการของเดือนนั้น · ถ้าจอบอก "ไม่มีสัญญาที่อยู่ในช่วงบริการของเดือน … ตามตัวกรองนี้ — ลองเปลี่ยนสาขา/เดือน" ลองเปลี่ยนตามนั้น

**ทำไมกดบันทึกไม่ได้?**
ดูกรอบ "บันทึกไม่ได้ — ยังขาด" ใต้ฟอร์ม แล้วกรอกช่องที่ขึ้นขอบแดงให้ครบ

**กรอกผิดไปแล้ว แก้ได้ไหม?**
ได้ — เลือกรายนั้นอีกครั้ง แก้ แล้วกดบันทึก (ทุกการแก้ลงประวัติการแก้ไขอัตโนมัติ)

**ตัดสิน "ไม่ชดเชย" ไปแล้วเปลี่ยนใจ?**
กด **เปิดเรื่องกลับ** (ดูงานประจำ 3)
