# คู่มือผู้ใช้ — AGA Bait Registry

**ฉบับใช้อบรม · ปรับล่าสุด 20 พ.ย. 2026** · อบรมทีม **ศุกร์ 27 พ.ย. 2026** · เปิดใช้งานจริง 1 ธ.ค. 2026

คู่มือฉบับนี้เขียนให้แอดมิน หัวหน้างาน และ PM / OM อ่าน ภาษาง่าย ไม่ต้องรู้เรื่องโปรแกรม
ชื่อปุ่ม ชื่อเมนู และข้อความเตือน ตรวจกับหน้าจอของระบบจริงแล้ว (ตรวจ ณ 20 พ.ย. 2026)

> **สถานะของคู่มือฉบับนี้**
> - ยังไม่มีภาพหน้าจอจริง — ใช้ป้าย `[ภาพหน้าจอ: …]` บอกตำแหน่งภาพที่จะใส่ (ภาพที่ใส่ต้องใช้ข้อมูลสมมติเท่านั้น ห้ามมีชื่อ/เบอร์/ที่อยู่ลูกค้าจริง)
> - ตัวอย่างชื่อ/เลขที่สัญญา/รหัสพนักงานทั้งหมดเป็น **ข้อมูลสมมติ** ไม่ใช่ข้อมูลจริง
> - หน้าที่ยังเป็นหน้าโครง ติดป้าย **⏳ รอหน้าจริง** ไว้ (จะเติมเมื่อหน้าจริงเสร็จ)

## คำที่ควรรู้

| คำ | ความหมาย |
|---|---|
| Host (QCS ส่วนกลาง Bait) | ส่วนกลางที่ดูแลระบบ = PM / OM / เจ้าของ |
| รหัสพนักงาน | ใช้เป็น "ชื่อผู้ใช้" ตอนเข้าสู่ระบบ (เช่น AG-01234 — สมมติ) |
| IG / IC | สถานีเหยื่อภายนอก (ตรวจทุกเดือน บันทึกเฉพาะจุดที่พบปลวก) |
| AG | กล่องเหยื่อ — ติดตามเป็นรอบ F1, F2, … จนถอด |
| ตกบริการ | เดือนที่อยู่ในสัญญาแต่ไม่มีการเข้าบริการ |
| Renew / New | สัญญาต่ออายุ / ลูกค้าใหม่ |
| ต่อสัญญาล่าช้า | งาน Renew ที่วันที่รับ Mail เป็นวันที่ 16 ของเดือนขึ้นไป |
| Tier (S / M / L / XL) | กลุ่มมูลค่าสัญญาต่อปี |
| ปิดเดือน | ยืนยันตัวเลขบริการของเดือนและส่งขึ้น Dashboard |
| Port | สรุปจำนวนลูกค้า/มูลค่าตาม Tier ของสาขาต่างจังหวัด ที่ PM / OM ลงเอง |

## หน้าที่ยังรอหน้าจริง (⏳) ณ วันที่ปรับคู่มือนี้

- **ทะเบียนลูกค้า/สัญญา** · **ลูกค้ารอเก็บสถานี** — ยังเป็นหน้าโครง (ผู้สอนจะแจ้งในวันอบรมว่าพร้อมหรือยัง)
- ข้อจำกัดอื่นที่ควรรู้: ปุ่ม "บันทึกบริการชดเชย" ยังไม่มีช่องระบุเดือนที่ชดเชย · ยังไม่พบปุ่ม "ยกเลิกสัญญา" · ยังไม่มีเมนูเปลี่ยนรหัสผ่านเอง · ยังไม่พบแถบแจ้งผู้ใช้เมื่อตำแหน่งถูกเปลี่ยน (รายละเอียดในแต่ละบท)

## ติดต่อ

เจอปัญหาหรือลืมรหัสผ่าน แจ้ง **PM / OM (Host — QCS ส่วนกลาง Bait)**
