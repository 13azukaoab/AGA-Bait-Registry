# คู่มือผู้ใช้ — AGA Bait Registry

**ร่างแรก: 17 พ.ย. 2026** · ใช้ในการอบรม 28–29 พ.ย. 2026 · เปิดใช้งานจริง 1 ธ.ค. 2026

คู่มือฉบับนี้เขียนให้แอดมินและหัวหน้างานอ่าน ภาษาง่าย ไม่ต้องรู้เรื่องโปรแกรม
ชื่อปุ่ม ชื่อเมนู และข้อความเตือน คัดจากหน้าจอของระบบจริง

> - ยังไม่มีภาพหน้าจอจริง — ใช้ป้าย `[ภาพหน้าจอ: …]` บอกตำแหน่งภาพที่จะใส่

> - หน้าที่ยังไม่เสร็จ ติดป้าย **⏳** ไว้ (จะเติมทีหลัง)

## คำที่ควรรู้

| คำ | ความหมาย |
|---|---|
| Host (QCS ส่วนกลาง Bait) | ส่วนกลางที่ดูแลระบบ = PM / OM / เจ้าของ |
| รหัสพนักงาน | ใช้เป็น "ชื่อผู้ใช้" ตอนเข้าสู่ระบบ (เช่น AG-01234 — สมมติ) |
| IG / IC | สถานีเหยื่อภายนอก (ตรวจทุกเดือน บันทึกเฉพาะจุดที่พบปลวก) |
| AG | กล่องเหยื่อ — ติดตามเป็นรอบ F1, F2, … จนถอด |
| ตกบริการ | เดือนที่อยู่ในสัญญาแต่ไม่มีการเข้าบริการ |
| Renew / New | สัญญาต่ออายุ / ลูกค้าใหม่ |
| Tier (S / M / L / XL) | กลุ่มมูลค่าสัญญาต่อปี |

## หน้าที่ยังไม่เปิดใช้ในร่างนี้ (⏳)

- ปิดเดือน (เมนู "ส่งข้อมูล และสรุปงานประจำเดือน") · Dashboard Sync · ประวัติการแก้ไข · ลงข้อมูล Port ต่างจังหวัด — คาดว่าพร้อมราว 22 พ.ย. 2026
- ทะเบียนลูกค้า/สัญญา · ลูกค้ารอเก็บสถานี · สรุปงานบริการรายเดือน — ยังไม่เปิดใช้ (ยังไม่มีวันที่ยืนยัน)

## ติดต่อ

เจอปัญหาหรือลืมรหัสผ่าน แจ้ง **PM / OM (Host — QCS ส่วนกลาง Bait)**
