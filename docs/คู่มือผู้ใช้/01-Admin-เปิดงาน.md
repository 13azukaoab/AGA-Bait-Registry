# 01 — แอดมิน (Admin) เปิดงาน

> ฉบับใช้อบรม **ศุกร์ 27 พ.ย. 2026** · ปรับล่าสุด 20 พ.ย. 2026 · ชื่อปุ่ม/เมนูตรวจกับหน้าจอจริงแล้ว · ชื่อลูกค้า เลขที่สัญญา ในคู่มือเป็น **ข้อมูลสมมติ**
> ยังไม่ได้อ่านบท `00-เริ่มใช้งานครั้งแรก.md`? อ่านก่อน (เข้าสู่ระบบ + ตั้งรหัสผ่านใหม่)

## ทำอะไรได้บ้าง

แอดมินคือคนที่ **เปิดงาน** — บันทึกสัญญาใหม่ / สัญญาต่ออายุเข้าระบบ ให้ไหลต่อไปถึงหัวหน้างาน

| ทำได้ | ทำไม่ได้ |
|---|---|
| เพิ่ม/แก้ลูกค้าและสัญญา (หน้า "เปิดงานเข้าทะเบียนบริการ") | กรอกผลบริการประจำเดือน (เมนูนี้ไม่ขึ้นให้แอดมิน) |
| แนบ PDF สัญญา + Site plan | กรอกงานกล่อง AG นอกรอบ |
| ลบสัญญาที่ **ยังไม่มีผลบริการ** | ปิดเดือน · ส่ง Dashboard |
| ดูสถานะทะเบียนบริการ (ดูอย่างเดียว) | ตัดสิน "ไม่ชดเชย" / บันทึกบริการชดเชย (ดูอย่างเดียว) |
| ดูรายละเอียดลูกค้า | ดูประวัติการแก้ไข (เฉพาะ PM / OM) |
| ดู Dashboard สรุปมูลค่าทั้งหมด · Dashboard งานขาย (New/Renew) · สรุปงานบริการรายเดือน | จัดการผู้ใช้ · ตั้งค่า |

ขอบเขตข้อมูล: แอดมินบันทึกได้เฉพาะ **สาขาในขอบเขตของบัญชี** (หน้าจอบอกไว้ใต้ชื่อหน้า)

## ⚠ อ่านก่อน: หน้าแรกของแอดมินยังเป็นหน้าโครง

หลังเข้าสู่ระบบ ระบบพาแอดมินไปหน้า **"ทะเบียนลูกค้า/สัญญา"** แต่หน้านี้ **ตอนนี้ยังเป็นหน้าโครง** (ขึ้นแค่ข้อความ "โครงหน้าจอ — ยังไม่ลงมือทำฟีเจอร์")
ให้กดเมนูซ้าย **"เปิดงานเข้าทะเบียนบริการ"** (กลุ่ม "ทะเบียนและสรุป") เพื่อเริ่มงานแทน — หน้านี้ใช้งานได้จริงและมีตารางรายชื่อสัญญาให้ค้นหา/แก้อยู่แล้ว

> ⏳ รอหน้าจริง · **ทะเบียนลูกค้า/สัญญา** (ตารางรายชื่อลูกค้าทั้งหมด)
> ยังไม่เปิดใช้ ณ วันที่ปรับคู่มือนี้ — ส่วนนี้จะเติมเมื่อหน้าจริงเสร็จ
>
> ⏳ รอหน้าจริง · **ลูกค้ารอเก็บสถานี** (ติดตามลูกค้าที่หมดสัญญาและต้องไปเก็บสถานีคืน)
> ยังไม่เปิดใช้ ณ วันที่ปรับคู่มือนี้ — ส่วนนี้จะเติมเมื่อหน้าจริงเสร็จ

ส่วนที่ใช้งานได้แล้วของแอดมิน: **เปิดงานเข้าทะเบียนบริการ** · **สถานะทะเบียนบริการ** (ดูอย่างเดียว) · **สรุปงานบริการรายเดือน** · **Dashboard งานขาย (New/Renew)** · **Dashboard สรุปมูลค่าทั้งหมด** · หน้ารายละเอียดลูกค้า

## งานประจำ 1: เปิดงานใหม่ (บันทึกสัญญาเข้าทะเบียน)

หน้าที่ใช้: เมนู **เปิดงานเข้าทะเบียนบริการ** → หัวหน้าจอ **"เปิดงาน · เพิ่มลูกค้าเข้าระบบ"**

หน้านี้เป็น **ตารางแบบ Excel**: 1 แถว = 1 สัญญา แถวใหม่ที่ยังไม่บันทึกจะอยู่ล่างสุดของตาราง

[ภาพหน้าจอ: หน้า "เปิดงาน · เพิ่มลูกค้าเข้าระบบ" ตัวกรองด้านบน + ตาราง + ปุ่ม "เพิ่มแถว" "บันทึกเข้าทะเบียน"]

### ขั้นตอน

1. เลือก **เดือนเปิดงาน** (ช่องซ้ายสุดด้านบน) ให้ตรงกับเดือนที่สัญญาเริ่ม
2. กดปุ่ม **เพิ่มแถว** (ได้แถวว่าง 1 แถว) — เพิ่มได้หลายแถวก่อนบันทึก
3. กรอกช่องในแถว (ช่องที่ **ต้องมี** ดูตารางข้างล่าง):

| ช่อง (หัวคอลัมน์) | กรอกอะไร | บังคับ? |
|---|---|---|
| เลขที่สัญญา | เลขที่สัญญา เช่น `CT26-0000142` (*ตัวอย่างสมมติ*) | ✅ |
| รายชื่อ | ชื่อลูกค้า (เช่น *บริษัท ตัวอย่าง จำกัด — สมมติ*) | ✅ |
| เบิกด่วน | ติ๊กถ้าเป็นงานเบิกด่วน | – |
| ประเภทงาน | กดเลือก **New** (ลูกค้าใหม่) หรือ **Renew** (ต่อสัญญา) | ✅ |
| ลูกค้าเดิม (Renew) | ใช้เมื่อเป็น Renew — ดูหัวข้อ "ต่อสัญญา (Renew)" ข้างล่าง | ตามประเภท |
| ผู้ขาย | ชื่อผู้ขาย (ถ้าว่าง จอแสดง "ยังไม่ใส่") | ✅ |
| ตำแหน่ง | ตำแหน่งของผู้ขาย | – |
| สาขา | พิมพ์ชื่อสาขา แล้วเลือกจากที่ระบบเสนอ (ถ้าขึ้น "ไม่พบสาขานี้ในรายการ — เลือกจากที่ระบบเดาให้" ให้เลือกจากรายการ) | ✅ |
| เขต | ระบบเติมให้ตามสาขา | (อัตโนมัติ) |
| วันที่รับ Mail | วันที่รับเอกสาร — ถ้าเป็นงาน Renew แล้ววันที่เกิน **วันที่ 15 ของเดือน** ระบบขึ้นสีแดงและป้าย "ต่อสัญญาล่าช้า" (ใช้นับใน Dashboard งานขาย) | – |
| วันที่บริการ | วันนัดเข้าบริการครั้งแรก — **ถ้ายังไม่นัด ปล่อยว่างได้** (สถานะจะเป็น "รอนัดบริการ" เติมทีหลังได้) | – |
| เวลาบริการ | เลือกเวลา (ต้องเลือกวันที่บริการก่อน) | – |
| ทีม | ทีมที่ดูแล — เลือกได้หลายทีมต่อ 1 สัญญา (เช่น A+E+Z) | – |
| ประเภท | ประเภทลูกค้า (เลือกจากรายการ) | – |
| เริ่มสัญญา | วันเริ่มสัญญา | ✅ |
| สิ้นสุด | ระบบเติมให้ = วันเริ่ม + ระยะสัญญา − 1 วัน · แก้เองได้ | (อัตโนมัติ) |
| มูลค่า 1 ปี / มูลค่า 3 ปี | **กรอกได้ช่องเดียว** ตามระยะสัญญา (ดูข้างล่าง) | ✅ |
| Tier | ระบบคำนวณให้ ไม่ต้องกรอก | (อัตโนมัติ) |
| หมายเหตุ | ข้อความเพิ่มเติม | – |
| ไฟล์แนบ | ปุ่ม **แนบ** — ดูงานประจำ 3 | แนะนำ (ไม่แนบก็บันทึกได้) |

> ใต้ตารางมีบอกว่า "ช่อง เขต / Tier / วันสิ้นสุด ระบบคำนวณให้ (ไม่ต้องกรอก)" — ไม่ต้องคำนวณเอง

4. **ระยะสัญญา (มูลค่า 1 ปี / 3 ปี / Custom)**
   - สัญญา 1 ปี → กรอกที่ช่อง **มูลค่า 1 ปี** · สัญญา 3 ปี → กรอกที่ช่อง **มูลค่า 3 ปี**
   - **กรอกได้ช่องเดียว** ถ้ากรอกทั้งสองช่อง จอเตือน "กรอกมูลค่าได้ช่องเดียว (1 ปี หรือ 3 ปี)"
   - สัญญาอื่นที่ไม่ใช่ 1 หรือ 3 ปี (เช่น 5 เดือน): กดลิงก์ **Custom…** ใต้ช่อง "มูลค่า 1 ปี" แล้วใส่ **จำนวนเดือน (1–35)** · ถ้าจะกลับมาเป็น 1 ปี กด **กลับเป็น 1 ปี**
   - Custom ใส่ 12 ไม่ได้ (จอเตือน "ระยะสัญญา Custom ต้องเป็นจำนวนเดือน 1–35 (ไม่ใช่ 12)") — 12 เดือน = สัญญา 1 ปี ให้ใช้ช่อง "มูลค่า 1 ปี"
5. ดูตัวนับใต้ตาราง: **"บันทึกได้ X จาก Y แถว"** · แถวที่ **ขอบแดง** = ยังขาดข้อมูลจำเป็น (ป้ายสถานะท้ายแถวบอกว่าขาดอะไร เช่น "ขาด เลขที่สัญญา · สาขา")
   - ยังไม่แนบไฟล์ = แค่เตือน ยังบันทึกต่อได้
6. กดปุ่ม **บันทึกเข้าทะเบียน** (มุมขวาล่างของตาราง)
7. ผลที่ขึ้น: "บันทึกเข้าทะเบียนครบ N แถว" ถ้าบางแถวไม่ผ่านจะบอกว่า "บันทึกสำเร็จ … · ไม่สำเร็จ … แถว (ดูข้อความใต้แถว)" — แก้แถวที่ไม่ผ่านแล้วกดบันทึกอีกรอบ
8. แถวที่บันทึกแล้วจะกลายเป็นแถวในตารางเดือนนั้น และไหลเข้าทะเบียนบริการให้หัวหน้างานกรอกผลต่อ

### ถ้าขึ้นหน้าต่าง "พบลูกค้าชื่อนี้ในสาขาแล้ว"

ระบบกันลูกค้าซ้ำ: ในสาขานี้มีลูกค้าชื่อเดียวกันอยู่แล้ว ให้เลือก:

- **ใช้ลูกค้ารายนี้** — เป็นลูกค้ารายเดิมจริง (ไม่นับลูกค้าซ้ำ)
- **เป็นคนละราย · สร้างลูกค้าใหม่** — คนละคนแต่ชื่อบังเอิญตรงกัน
- **ยกเลิก (ยังไม่บันทึกแถวนี้)** — ถอยกลับไปเช็กก่อน

> ถ้าปิดหน้าต่างโดยไม่เลือก ระบบยกเลิกการบันทึกแถวนั้นและบอกว่า "ยังไม่ได้เลือกว่าเป็นรายเดิมหรือคนละราย กดบันทึกใหม่เพื่อเลือก"

### ต่อสัญญา (Renew)

1. ที่ช่อง **ประเภทงาน** กด **Renew**
2. ช่อง **ลูกค้าเดิม (Renew)** → กด **⚠ ยังไม่ผูก · ค้นหา** เปิดหน้าต่าง **"ผูกลูกค้าเดิม (Renew)"**
3. พิมพ์ชื่อลูกค้า หรือเลขที่สัญญาเดิม (อย่างน้อย 2 ตัวอักษร) แล้วเลือกสัญญาเก่า
   → สัญญาใหม่ใช้ลูกค้าคนเดียวกัน ไม่สร้างลูกค้าใหม่ (และสาขา/ชื่อลูกค้าจะถูกล็อกตามสัญญาเก่า)
4. กติกาที่ระบบเช็กให้:
   - วันเริ่มสัญญาใหม่ต้องอยู่ **หลังวันเริ่มสัญญาเก่า**
   - Renew ได้เมื่อเริ่มไม่เกิน **2 เดือนหลังสัญญาเก่าจบ** — เกินกว่านั้น จอบอกว่า "ต้องเปิดเป็น New"
5. **หาสัญญาเก่าไม่เจอ?** (ในช่วงแรกของการใช้ระบบเท่านั้น) เลือก Renew แบบไม่ผูกได้ แต่ต้องกรอก **"เหตุผลที่ไม่ผูกสัญญาเก่า (บังคับ)"** — แถวนั้นจะขึ้นให้ส่วนกลางตรวจและผูกย้อนหลัง
   หมดช่วงนี้แล้ว จอจะบอกว่า "ช่วงเปิด Renew แบบไม่ผูกสิ้นสุดแล้ว — ต้องผูกสัญญาเก่า หรือเปิดเป็น New"
6. ถ้าผูกผิด: กด **✕** ที่ช่องลูกค้าเดิมเพื่อ "เลิกผูกลูกค้าเดิม" (ก่อนบันทึกเท่านั้น)

> ภายหลังบันทึกแล้ว ถ้าแถว Renew ยังไม่ผูกสัญญาเก่า จะมีปุ่ม **"เชื่อมสัญญาเก่า"** ให้กดเข้าไปผูกย้อนหลัง หรือกด **"ไม่มีสัญญาเก่าในระบบ"** เมื่อตรวจแล้วว่าไม่มีจริงๆ
> ⚠ ช่องหมายเหตุตอนปิดรายการ **ห้ามใส่ข้อมูลส่วนตัวของลูกค้า** (หัวหน้างานอ่านได้)

## งานประจำ 2: แก้สัญญาที่บันทึกไปแล้ว

1. หาแถวของสัญญา (ใช้ช่อง **กรองในตารางนี้** พิมพ์ชื่อลูกค้า/เลขที่สัญญา · หรือกรอง **เขต / สาขา / สถานะ**)
   ตัวเลือกช่อง **สถานะ**: ครบแล้ว · รอนัดบริการ · ขาดข้อมูลจำเป็น · ยังไม่แนบไฟล์ · มีคำเตือนอื่น (ระยะสัญญา/วันที่)
   ถ้าเจอข้อความ "เดือนนี้มีสัญญามากกว่าที่แสดงได้ในหน้าเดียว" → ใช้ตัวกรองสาขา/เขตเพื่อดูส่วนที่เหลือ
2. กดปุ่ม **แก้** ท้ายแถว → ช่องในแถวกลายเป็นช่องกรอก
3. แก้ค่าที่ต้องการ แล้วกด **บันทึก** (ถ้าเปลี่ยนใจ กด **ยกเลิก** = คืนค่าเดิม)
4. ถ้าแก้วันเริ่มสัญญาข้ามเดือน แถวนั้นจะย้ายไปอยู่ในเดือนใหม่ — จอบอก "วันเริ่มย้ายไปเดือน … (ดูได้ที่เดือนนั้น)"

**แก้ไม่ได้หลังบันทึก** (จอจะบอกเหตุผลเมื่อเอาเมาส์ชี้ — ถ้าลงผิด ให้ลบสัญญาแล้วเปิดงานใหม่ หรือแจ้ง PM/OM):

- **สาขา** — "แก้สาขาไม่ได้ — ถ้าลงผิดสาขาให้ลบสัญญานี้แล้วเปิดงานใหม่"
- **ชื่อลูกค้า** — "แก้ชื่อลูกค้าในหน้านี้ไม่ได้ — ลูกค้า 1 คนมีได้หลายสัญญา การแก้ชื่อจะกระทบทุกสัญญาของลูกค้าคนนี้"
- **ประเภทลูกค้า** — "ประเภทลูกค้าเป็นของลูกค้า ไม่ใช่ของสัญญา — แก้ในหน้านี้ไม่ได้"
- **New ↔ Renew** — "สลับ New/Renew ไม่ได้หลังบันทึก — ถ้าลงผิดประเภท ให้ลบสัญญานี้แล้วเปิดงานใหม่ (หรือแจ้งผู้ดูแลระบบ)"
- **สัญญาที่ปิดแล้ว/ยกเลิกแล้ว** — "แก้ไม่ได้ — สัญญาปิดแล้ว (เก็บไว้เป็นประวัติ · แก้ได้เฉพาะ host)"

ถ้าเจอ "มีคนแก้สัญญานี้ไปก่อนแล้ว กรุณาโหลดใหม่" → กดปุ่ม **โหลดแถวใหม่** ที่ใต้แถว แล้วแก้ต่อจากค่าล่าสุด

## งานประจำ 3: แนบไฟล์สัญญา (PDF) + Site plan

1. ที่ท้ายแถวสัญญา กดปุ่ม **แนบ** (ถ้าแนบแล้วปุ่มจะเป็น **PDF ✓**) → เปิดหน้าต่าง **"ไฟล์แนบ"**
2. หัวข้อ **"PDF สัญญา + Site plan (ไฟล์เดียว · PDF เท่านั้น)"** → กด **เลือกไฟล์ PDF** (ถ้าเปลี่ยนไฟล์: **เปลี่ยนไฟล์ PDF**) · ไม่ต้องการไฟล์ที่เลือกไว้: **เอาออก**
3. สำหรับแถวที่ยังไม่บันทึก ไฟล์จะอัปโหลดตอนกด **บันทึกเข้าทะเบียน**
4. **ข้อกำหนดไฟล์** (ย่อจาก `docs/คู่มือสแกนและแนบไฟล์สัญญา.md`):
   - ความละเอียด **150–200 dpi** · โหมด **ขาวดำ หรือ เทา** (ใช้สีเต็มเฉพาะกรณีสัญญามีของที่ต้องเห็นสีจริง)
   - **1 สัญญา = 1 ไฟล์ PDF หลายหน้า** ห้ามแยกเป็นรูปรายหน้า
   - **ไม่เกิน 5 MB** — เกินแล้วจอบอก "PDF ต้องไม่เกิน 5 MB — ถ้าใหญ่กว่าให้สแกนใหม่ที่ 150–200 dpi แบบขาวดำหรือเทา"
   - ตั้งชื่อไฟล์ `CTyy-nnnnnnn.pdf` ให้ตรงกับเลขที่สัญญา (แนะนำ เพื่อหาไฟล์ง่าย) เช่น `CT26-0000142.pdf` (*สมมติ*)
5. **อัปเดต Site plan** (หลังแนบ PDF สัญญาแล้ว — เช่น แก้ตอนติดตั้ง): กรอก **"เหตุผลที่แก้ Site plan (จำเป็น)"** ก่อน แล้วกด **เลือกไฟล์ Site plan (PDF / PNG / JPG)** · ระบบเก็บทุกเวอร์ชัน
   - ถ้ายังไม่แนบ PDF สัญญา → จอบอก "ต้องแนบ PDF สัญญาก่อน จึงจะอัปเดต Site plan ได้"
6. ลบไฟล์: กด **ลบ** ข้างไฟล์ (ระบบถามยืนยัน — ลบแล้วเอากลับคืนไม่ได้) · ดูไฟล์: **เปิดดู**
7. สัญญาที่ **ปิดแล้ว** ไฟล์ถูกล็อก: "สัญญาปิดแล้ว ไฟล์ถูกล็อก เปิดดูได้อย่างเดียว"

[ภาพหน้าจอ: หน้าต่าง "ไฟล์แนบ" ส่วน PDF สัญญา + ส่วนอัปเดต Site plan]

## งานประจำ 4: ลบสัญญา

- กดปุ่ม **✕** ท้ายแถว → ระบบถามยืนยัน (ลบแล้วเอากลับคืนไม่ได้ · ไฟล์แนบถูกลบด้วย)
- **ลบได้เฉพาะสัญญาที่ยังไม่มีผลบริการ** ถ้ามีผลบริการแล้วจอบอก "ลบไม่ได้ เพราะสัญญานี้มีผลบริการหรือผลตรวจสถานีแล้ว (ให้ใช้สถานะยกเลิกแทน)" → แจ้ง PM / OM (ตอนนี้ **ยังไม่พบปุ่ม "ยกเลิกสัญญา"** ในหน้าจอ — PM / OM จะแนะนำวิธีจัดการให้)
- ถ้าสัญญานี้มีสัญญา Renew ผูกอยู่ จอเตือนก่อนลบ ว่าสัญญา Renew เหล่านั้นจะกลายเป็น "ยังไม่ผูก"
- สัญญาที่ปิดแล้ว/ยกเลิกแล้วลบไม่ได้ (เก็บไว้เป็นประวัติ)

## งานประจำ 5: ดูรายละเอียดลูกค้า

หน้า **รายละเอียดลูกค้า** เปิดจากลิงก์ชื่อลูกค้าในหน้าอื่น (มี 6 แท็บ: **ภาพรวม · สัญญา · สถานี · ประวัติทำบริการ · ไฟล์แนบ · ไทม์ไลน์**)

แอดมินทำได้:
- แท็บ **ภาพรวม** ดูตัวเลขสำคัญ + งานที่ต้องทำ
- ข้อมูลติดต่อ (แผงข้อมูลลูกค้า): แก้ **ผู้ติดต่อ · โทร · หมายเหตุ** ได้ — กดไอคอนดินสอ แล้วกดบันทึก (ลงประวัติการแก้ไขอัตโนมัติ) · เพิ่ม/ลบเบอร์ได้ (**เพิ่มเบอร์** / **ลบเบอร์**)
- ปุ่ม **แก้ข้อมูลลูกค้า** → ไปหน้าเปิดงานเพื่อแก้
- แท็บ **ไฟล์แนบ**: **ดู** / **ดาวน์โหลด** ไฟล์ (เปิดผ่านลิงก์ชั่วคราว ไม่มีลิงก์สาธารณะ)

แอดมินทำไม่ได้: ลงผลบริการ (ปุ่ม "ลงข้อมูลทำบริการประจำเดือน" เป็นของหัวหน้างาน) · แท็บ **ไทม์ไลน์** ดูได้เฉพาะ PM / OM

> ถ้าลูกค้ารายนั้นเป็นของทีมอื่น จอจะถามยืนยันก่อนแก้ข้อมูลติดต่อ ("ลูกค้าของทีมอื่น") → กด **ยืนยัน แก้ไข** ถ้าแน่ใจ

## งานประจำ 6: ดูสถานะทะเบียนบริการ (ดูอย่างเดียว)

เมนู **สถานะทะเบียนบริการ** — แอดมินใช้ดูว่าเดือนนี้ลงผลไปถึงไหน
แอดมิน **ดูอย่างเดียว** (ปุ่ม "ไม่ชดเชย" / "บันทึกบริการชดเชย" ใช้ไม่ได้ — จอแสดง "ดูอย่างเดียว")
รายละเอียดหน้านี้อ่านในบท `02-หัวหน้างาน.md`

## งานประจำ 7: ดู Dashboard งานขาย (New/Renew)

หน้าที่ใช้: เมนู **Dashboard งานขาย (New/Renew)** (กลุ่ม "ทะเบียนและสรุป") — **เฉพาะแอดมิน และ PM / OM** (หัวหน้างานไม่เห็นเมนูนี้)

หน้านี้ดูอย่างเดียว ไม่มีอะไรให้กรอก บอกว่า "งานใหม่ (New) และต่อสัญญา (Renew) แยกตามสาขา เขต และผู้ขาย · **นับตามเดือนที่รับ Mail**" (ข้อมูล 12 เดือนล่าสุด)

[ภาพหน้าจอ: หน้า "Dashboard งานขาย (New/Renew)" แถบตัวกรอง + การ์ด 4 ใบ + กราฟ + อันดับผู้ขาย (ข้อมูลสมมติ)]

1. **ตัวกรองด้านบน:** **ตั้งแต่เดือน** · **ถึงเดือน** · **เขต** · **สาขา** · **ผู้ขาย** (มีตัวเลือก "ไม่ระบุผู้ขาย" ด้วย) — กด **ล้างตัวกรอง** เพื่อเริ่มใหม่
2. **แถบ "ประเภทงาน"** (ค้างอยู่ตอนเลื่อนหน้า): **ทั้งหมด** · **New** · **Renew** — เลือกแล้วการ์ด กราฟ อันดับเปลี่ยนตาม
3. **การ์ดตัวเลข:** **งานใหม่ (New)** · **ต่อสัญญา (Renew)** · **ต่อสัญญาล่าช้า** · **รวมทั้งหมด** (แต่ละใบบอกจำนวนราย และมูลค่า)
4. **กราฟ:** **แนวโน้มรายเดือน** · **แยกตามเขต**
5. **อันดับ:** **อันดับผู้ขาย** · **ยอดรายสาขา**
6. **รายชื่อลูกค้า:** กดชื่อเพื่อเปิดหน้าลูกค้า · ปุ่มกรอง **ทั้งหมด** / **ต่อสัญญาล่าช้า** (ซ่อนเมื่อเลือกประเภทงานเป็น New) · กด **แสดงเพิ่ม** เพื่อดูรายการถัดไป

**ควรรู้:**

- **"ต่อสัญญาล่าช้า"** = งาน Renew ที่วันที่รับ Mail เป็น **วันที่ 16 ของเดือนขึ้นไป** (วันที่ 15 ยังไม่ล่าช้า) · งาน New ไม่นับ
- งานที่ **ไม่มีวันที่รับ Mail** ไม่ถูกนับในยอดและกราฟ — หน้าจอบอกจำนวนไว้ใต้การ์ด ("ไม่มีวันที่รับ Mail N ราย ทั้งระบบ") · ถ้าตัวเลขดูน้อยไป ให้ตรวจว่ากรอก **วันที่รับ Mail** ในหน้าเปิดงานครบหรือยัง
- ถ้าขึ้นแถบเหลือง **"แสดงข้อมูลบางส่วน"** = ข้อมูลมากเกินกว่าจะโหลดครบ ตัวเลขอาจต่ำกว่าจริง ให้จำกัดช่วงเดือนให้แคบลง
- หน้านี้มีชื่อลูกค้า — **ห้ามแคปหน้าจอส่งต่อคนนอกทีม**

## งานประจำ 8: ดูสรุปงานบริการรายเดือน

เมนู **สรุปงานบริการรายเดือน** (กลุ่ม "ทะเบียนและสรุป") — แอดมิน หัวหน้างาน และ PM / OM เปิดได้ · ดูอย่างเดียว
วิธีใช้และความหมายของตัวเลขอยู่ในบท `02-หัวหน้างาน.md` หัวข้อ "งานประจำ 6"

## ข้อควรระวัง

- **บันทึกแล้วจึงจะเข้าทะเบียน** — แถวที่ยังไม่กด **บันทึกเข้าทะเบียน** จะหายถ้าปิดหน้า
- **เดือนเปิดงาน** ที่เลือกด้านบนมีผลกับตารางที่เห็น — ถ้าหาสัญญาไม่เจอ เช็กก่อนว่าเลือกเดือนตรงกับ **วันเริ่มสัญญา** หรือยัง
- **ห้ามใส่ข้อมูลส่วนตัวลูกค้าเกินจำเป็นในช่องหมายเหตุ** (คนอื่นอ่านได้)
- ไฟล์สแกนใหญ่เกิน 5 MB ระบบไม่รับ — สแกนใหม่ให้เล็กลงตามข้อกำหนดข้างบน

## ถามบ่อย

**ผมเปิดงานแล้ว ทำไมลูกค้าไม่ขึ้นในหน้าลงผลบริการของหัวหน้างาน?**
หน้าลงผลบริการแสดงเฉพาะสัญญาที่ **อยู่ในช่วงบริการของเดือนที่เลือก** — เช็กเดือนเริ่มสัญญา และให้หัวหน้างานเลือกเดือน/สาขาให้ตรง

**พิมพ์เลขที่สัญญาผิด แก้ได้ไหม?**
แก้ได้ที่ปุ่ม **แก้** (ถ้าสัญญายังไม่ปิด/ยกเลิก)

**ลงผิดสาขา ทำยังไง?**
แก้สาขาไม่ได้ ให้ลบสัญญาแล้วเปิดงานใหม่ (ลบได้เฉพาะที่ยังไม่มีผลบริการ) · ถ้ามีผลบริการแล้ว แจ้ง PM / OM

**เห็นข้อความ "เบิกด่วน" "SP 1" ในแถว คืออะไร?**
"เบิกด่วน" = งานที่ติ๊กว่าเบิกด่วน · "SP n" ข้างปุ่มไฟล์ = จำนวนครั้งที่อัปเดต Site plan
