# 00 — เริ่มใช้งานครั้งแรก (ทุกตำแหน่งอ่าน)

> ร่างแรก 17 พ.ย. 2026 · ชื่อปุ่ม/เมนูในคู่มือนี้คัดจากหน้าจอจริงของระบบ · ตัวอย่างชื่อ/รหัสในคู่มือเป็น **ข้อมูลสมมติ** ไม่ใช่ลูกค้าหรือพนักงานจริง

## ระบบนี้คืออะไร (สั้นๆ)

AGA Bait Registry คือระบบทะเบียนบริการเหยื่อ (Bait) ที่มาแทนไฟล์ Excel ของแต่ละสาขา
ทุกคนใช้ข้อมูลชุดเดียวกัน — ไม่ต้องส่งไฟล์ไปมา

## ก่อนเริ่ม: ใครเป็นใคร

ระบบมี 4 ตำแหน่งที่ต้องมีบัญชี และ 1 กลุ่มที่ไม่ต้องมีบัญชี

| ตำแหน่ง | อ่านบทไหน |
|---|---|
| แอดมิน (Admin) — เปิดงาน | `01-Admin-เปิดงาน.md` |
| หัวหน้างาน (Supervisor) | `02-หัวหน้างาน.md` |
| PM · OM (และ "เจ้าของ") | `03-PM-OM.md` |
| ผู้ดูทั่วไป (ไม่มีบัญชี) | `04-ผู้ดูทั่วไป.md` |

> **คำว่า "Host (QCS ส่วนกลาง Bait)"** ที่ขึ้นในข้อความบนจอ = ส่วนกลางที่ดูแลระบบ คือกลุ่ม PM / OM / เจ้าของ
> ถ้าจอบอกให้ "ติดต่อ Host" ให้ติดต่อ PM หรือ OM

## 1. เข้าสู่ระบบครั้งแรก

หน้าที่ใช้: **เข้าสู่ระบบ** (`/login`)

คุณจะได้รับ 2 อย่างจากส่วนกลาง (PM / OM) — ส่งให้ด้วยตัวเอง เช่น โทรหรือแชตส่วนตัว:

1. **ชื่อผู้ใช้** — คือ **รหัสพนักงาน** ของคุณ (รูปแบบ AG-ตามด้วยตัวเลข เช่น `AG-01234` ← *ตัวอย่างสมมติ*)
2. **รหัสผ่านชั่วคราว** — ระบบสุ่มให้ ใช้ได้แค่ครั้งแรก

ขั้นตอน:

1. เปิดลิงก์ของระบบที่ส่วนกลางแจ้ง
2. ช่อง **ชื่อผู้ใช้** — พิมพ์รหัสพนักงาน
   (ใต้ช่องมีข้อความว่า "ใช้ชื่อผู้ใช้ที่ Host สร้างให้ ไม่ต้องพิมพ์อีเมล" — **ไม่ต้องพิมพ์อีเมลเด็ดขาด**)
3. ช่อง **รหัสผ่าน** — พิมพ์รหัสชั่วคราว
   (กดไอคอนตา 👁 ข้างช่อง เพื่อ "แสดงรหัสผ่าน" ตรวจว่าพิมพ์ถูก และกดอีกครั้งเพื่อ "ซ่อนรหัสผ่าน")
4. กดปุ่ม **เข้าสู่ระบบ**

[ภาพหน้าจอ: หน้าเข้าสู่ระบบ ช่องชื่อผู้ใช้ + รหัสผ่าน + ปุ่ม "เข้าสู่ระบบ"]

## 2. ตั้งรหัสผ่านใหม่ (บังคับ — ข้ามไม่ได้)

เข้าด้วยรหัสชั่วคราวแล้ว ระบบจะพาไปหน้า **"ตั้งรหัสผ่านใหม่ก่อนเริ่มใช้งาน"** (`/change-password`) ทันที
**ต้องตั้งรหัสใหม่ให้เสร็จก่อน จึงจะเข้าหน้าอื่นของระบบได้**

หน้านี้จะแสดงข้อความ "บัญชีนี้ยังใช้รหัสผ่านที่ Host ตั้งให้ ต้องตั้งรหัสผ่านใหม่ก่อนเข้าใช้งานหน้าอื่น"
พร้อมชื่อและตำแหน่งของคุณ (ช่วยเช็กว่าเข้าบัญชีถูกคน)

ขั้นตอน:

1. ช่อง **รหัสผ่านใหม่** — ตั้งรหัสตามกติกา:
   - ยาวอย่างน้อย **8 ตัวอักษร**
   - มีตัวพิมพ์ใหญ่ (A–Z) อย่างน้อย 1 ตัว
   - มีตัวพิมพ์เล็ก (a–z) อย่างน้อย 1 ตัว
   - มีตัวเลข (0–9) อย่างน้อย 1 ตัว
   - **ต้องไม่ซ้ำกับรหัสผ่านเดิม** (รหัสชั่วคราว)
   - ตัวอย่างรหัสที่ผ่านกติกา: `Bait2026ok` ← *ตัวอย่างสมมติ ห้ามใช้รหัสนี้จริง*
2. ช่อง **ยืนยันรหัสผ่านใหม่** — พิมพ์ซ้ำให้เหมือนช่องแรก
3. กดปุ่ม **บันทึกรหัสผ่านใหม่**
4. เสร็จแล้วระบบพาเข้าหน้าแรกของตำแหน่งคุณ (ดูหัวข้อ 4)

[ภาพหน้าจอ: หน้า "ตั้งรหัสผ่านใหม่ก่อนเริ่มใช้งาน" ช่องรหัสผ่านใหม่ + ยืนยัน + ปุ่ม "บันทึกรหัสผ่านใหม่"]

ข้อความเตือนที่อาจเจอ และวิธีแก้:

| ข้อความบนจอ | ต้องทำอะไร |
|---|---|
| รหัสผ่านใหม่ไม่ผ่านเงื่อนไข: … (ตามด้วยข้อที่ขาด เช่น "ต้องมีตัวพิมพ์ใหญ่อย่างน้อย 1 ตัว") | แก้รหัสให้ครบตามข้อที่จอบอก |
| รหัสผ่านใหม่ทั้งสองช่องไม่ตรงกัน | พิมพ์ช่อง "ยืนยัน" ให้เหมือนช่องแรก |
| รหัสผ่านใหม่ต้องไม่ซ้ำกับรหัสผ่านเดิม | ตั้งรหัสที่ต่างจากรหัสชั่วคราว |
| รหัสผ่านนี้เคยรั่วไหลหรือเดาง่ายเกินไป กรุณาเลือกรหัสอื่น | เลือกรหัสอื่นที่เดายากกว่านี้ |

## 3. เข้าสู่ระบบครั้งต่อไป

ใส่ **ชื่อผู้ใช้** (รหัสพนักงาน) + **รหัสผ่านใหม่ที่คุณตั้งเอง** แล้วกด **เข้าสู่ระบบ**

ข้อความที่อาจเจอ:

| ข้อความบนจอ | ความหมาย / ต้องทำอะไร |
|---|---|
| ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง | พิมพ์ผิด ลองใหม่ (ระบบตั้งใจไม่บอกว่าผิดช่องไหน เพื่อความปลอดภัย) |
| กรอกชื่อผู้ใช้และรหัสผ่าน | ยังไม่ได้กรอกครบ 2 ช่อง |
| บัญชีนี้ถูกปิดการใช้งาน ติดต่อ Host (QCS ส่วนกลาง Bait) | บัญชีถูกปิด — แจ้ง PM / OM |
| บัญชีนี้ยังไม่ได้ตั้งค่าในระบบ ติดต่อ Host (QCS ส่วนกลาง Bait) | บัญชีสร้างไม่ครบ — แจ้ง PM / OM |
| เครือข่ายขัดข้อง ลองอีกครั้ง หากยังเข้าไม่ได้ให้ติดต่อ Host | เน็ตมีปัญหา — ตรวจสัญญาณแล้วลองใหม่ |

## 4. หน้าแรกหลังเข้าระบบ + เมนูที่เห็น

ระบบพาไปหน้าแรกตามตำแหน่ง และ **เมนูซ้ายมือจะเห็นไม่เท่ากัน** — เมนูที่คุณไม่มีสิทธิ์จะไม่ขึ้นเลย (ไม่ใช่ว่าระบบเสีย)

| ตำแหน่ง | หน้าแรก | เมนูที่เห็น |
|---|---|---|
| แอดมิน (Admin) | ทะเบียนลูกค้า/สัญญา | สถานะทะเบียนบริการ · ลูกค้ารอเก็บสถานี · ทะเบียนลูกค้า/สัญญา · เปิดงานเข้าทะเบียนบริการ · สรุปงานบริการรายเดือน · Dashboard สรุปมูลค่าทั้งหมด |
| หัวหน้างาน | สถานะทะเบียนบริการ | สถานะทะเบียนบริการ · ลงข้อมูลทำบริการประจำเดือน · กล่อง AG นอกรอบประจำเดือน · ลูกค้ารอเก็บสถานี · ทะเบียนลูกค้า/สัญญา · สรุปงานบริการรายเดือน · Dashboard สรุปมูลค่าทั้งหมด · ส่งข้อมูล และสรุปงานประจำเดือน |
| PM · OM · เจ้าของ | สถานะทะเบียนบริการ | เห็นครบทุกเมนู รวมกลุ่ม "ดูแลระบบ" (ส่งข้อมูล และสรุปงานประจำเดือน · ลงข้อมูล Port ต่างจังหวัด · Dashboard Sync · ประวัติการแก้ไข · จัดการผู้ใช้ · ตั้งค่า) |

เมนูแบ่งเป็น 3 กลุ่มหัวข้อ: **งานประจำวัน** · **ทะเบียนและสรุป** · **ดูแลระบบ**

> ⚠ บางเมนูในตารางนี้ **ยังเปิดไม่ได้ในตอนนี้** (หน้ายังไม่เสร็จ) — แต่ละบทตำแหน่งจะบอกเองว่าเมนูไหนพร้อมแล้ว

[ภาพหน้าจอ: เมนูซ้ายของตำแหน่งหัวหน้างาน แสดง 3 กลุ่มหัวข้อ]

## 5. แถบด้านบน (ทุกหน้า)

- **เดือน** — เลือกเดือนที่จะทำงาน (ตัวเลือกเริ่มตั้งแต่เดือนเริ่มใช้ระบบจนถึงเดือนปัจจุบัน)
- **ปุ่มโหมดสี** — สลับ "ตามเครื่อง" / "สว่าง" / "มืด"
- **ออกจากระบบ** — ดูหัวข้อ 6
- กดโลโก้ AGA มุมซ้ายบน = กลับหน้า "สถานะทะเบียนบริการ"
- จอมือถือ: กดปุ่ม ☰ ("เปิดเมนู" / "ปิดเมนู") เพื่อเปิด-ปิดเมนูซ้าย

## 6. ออกจากระบบ

1. กดปุ่ม **ออกจากระบบ** มุมขวาบน (ไอคอน ⏻)
2. ระบบถามว่า "ออกจากระบบของ … ใช่หรือไม่" → กดปุ่ม **ออกจากระบบ** เพื่อยืนยัน
   (ถ้ากดผิด ให้กด **กลับหน้าเดิม**)
3. กลับมาหน้าเข้าสู่ระบบ พร้อมข้อความ "ออกจากระบบแล้ว"

> ใช้เครื่องร่วมกับคนอื่น (เช่น คอมกลางสาขา) **ควรออกจากระบบทุกครั้งที่เลิกใช้**

## 7. ลืมรหัสผ่าน ทำยังไง

**ระบบไม่มีการรีเซ็ตรหัสผ่านทางอีเมล** และไม่มีปุ่ม "ลืมรหัสผ่าน" ให้กดเอง

1. แจ้ง **PM / OM (ส่วนกลาง)** ว่าลืมรหัส
2. ส่วนกลางกด "รีเซ็ตรหัส" ให้ → คุณจะได้ **รหัสชั่วคราวใหม่** (รหัสเดิมใช้ไม่ได้ทันที)
3. เข้าสู่ระบบด้วยรหัสชั่วคราว → ระบบบังคับตั้งรหัสใหม่อีกครั้ง (ตามหัวข้อ 2)

## ถามบ่อย

**ทำไมเมนูของเพื่อนผมมีมากกว่าผม?**
เมนูขึ้นตามตำแหน่ง เพื่อนอาจเป็นคนละตำแหน่ง ไม่ใช่ว่าระบบผิดพลาด

**เปลี่ยนรหัสผ่านทีหลังเองได้ไหม?**
ตอนนี้ยังไม่มีเมนู "เปลี่ยนรหัสผ่าน" ในแถบเมนู — ถ้าอยากเปลี่ยนรหัส ให้ขอส่วนกลางรีเซ็ตให้ แล้วตั้งใหม่ตามหัวข้อ 2

**จอขึ้น "มีเวอร์ชันใหม่ กดเพื่ออัปเดต" คืออะไร?**
ระบบมีเวอร์ชันใหม่ กด **อัปเดตตอนนี้** ได้เลย หรือกด **ภายหลัง** ถ้ากำลังกรอกข้อมูลค้างอยู่
(ถ้ามีข้อมูลที่ยังไม่บันทึก จอจะเตือน "มีข้อมูลที่ยังไม่บันทึก จะหายถ้าอัปเดตตอนนี้" — **บันทึกก่อนค่อยอัปเดต**)
