ก่อนเริ่ม — อ่านก่อน 1 นาที

  • ใช้บัญชีแยกตามตำแหน่ง PM/OM สร้างให้ที่เมนู “จัดการผู้ใช้” · ข้อที่ติดป้าย บัญชีใหม่ ต้องใช้บัญชีที่ยังไม่เคยเข้าระบบเลย จึงควรเตรียมบัญชีใหม่ไว้ตำแหน่งละ 1 บัญชี
  • ระบบที่ทดสอบคือ ระบบจริง ข้อมูลที่กรอกจะถูกบันทึกจริง · ให้ใช้ชื่อสมมติ เช่น “บริษัท ทดสอบ UAT จำกัด (สมมติ)” และเลขที่สัญญาสมมติ เช่น CT26-9990001 · ห้ามใช้ข้อมูลลูกค้าจริง · ถ้าจะแนบไฟล์ ใช้ PDF ตัวอย่างเท่านั้น
  • ข้อที่ติดป้าย กระทบข้อมูลจริง คือข้อที่บันทึก/ส่งข้อมูลขึ้นระบบจริง โดยเฉพาะการปิดเดือน, “ส่งตอนนี้”, และ “คำนวณ snapshot ใหม่ + ส่ง Dashboard” ที่ส่งตัวเลขขึ้น AGA Bait Dashboard จริง — หยุดคิดก่อนกดปุ่มสุดท้ายของข้อเหล่านี้
  • ข้อที่ติดป้าย รอหน้าจริง คือหน้าที่ยังเป็นหน้าโครงหรือยังไม่เปิดในระบบ — ให้ดูว่าไม่ทำให้ส่วนอื่นพัง แล้วเลือก “ข้าม” ไม่นับเป็นไม่ผ่าน
  • ข้อที่ติดป้าย สิทธิ์ · ต้องเข้าไม่ได้ คือลองเข้าสิ่งที่ตำแหน่งนี้ ไม่ควรเข้าได้ · ถ้าเข้าได้ = ไม่ผ่านทันที (สำคัญที่สุดของใบนี้)
  • วิธีลองพิมพ์ลิงก์: คลิกช่องที่อยู่เว็บด้านบน ลบท้ายลิงก์เดิม พิมพ์ท้ายลิงก์ใหม่ เช่น /admin/users แล้วกด Enter
  • สิ่งที่ติ๊กและพิมพ์บนจอนี้ เก็บไว้ในเครื่อง/เบราว์เซอร์นี้เท่านั้น ไม่ส่งไปที่ไหน · ถ้าจะส่งต่อหรือเก็บเป็นหลักฐาน ให้กด “พิมพ์ / บันทึกเป็น PDF” ด้านล่าง

ส่วนที่ 1 · Admin (เปิดงาน)

ตำแหน่งที่เปิดงาน — บันทึกสัญญาใหม่ / ต่อสัญญาเข้าทะเบียน · เห็นเมนู 6 รายการ (ไม่มีกลุ่ม “ดูแลระบบ”) · หน้าแรกหลังเข้าระบบคือ “ทะเบียนลูกค้า/สัญญา”

A1

เข้าครั้งแรก · ตั้งรหัสใหม่ · บทสอนใช้งาน (เริ่มเอง ข้ามได้ ดูซ้ำได้)

บทสอนใช้งานบัญชีใหม่

ให้ลองทำอะไร

  1. ใช้บัญชี Admin ที่ ยังไม่เคยเข้าระบบเลย เข้าหน้า “เข้าสู่ระบบ” ใส่รหัสพนักงาน + รหัสชั่วคราวที่ PM/OM ให้ แล้วกด “เข้าสู่ระบบ”
  2. ที่หน้า “ตั้งรหัสผ่านใหม่ก่อนเริ่มใช้งาน” ตั้งรหัสใหม่ + พิมพ์ซ้ำ แล้วกด “บันทึกรหัสผ่านใหม่”
  3. ดูว่าบทเรียนเริ่มเองหรือไม่ · ลองกด “ถัดไป” / “ย้อน” / “ข้ามทั้งหมด (Esc)” · ในบทเรียนลองกดปุ่มบันทึกที่ไฟกระพริบ
  4. ออกจากระบบแล้วเข้าใหม่ด้วยรหัสที่ตั้งเอง → กดปุ่ม “สอนใช้งาน” มุมขวาบน

ผลที่ควรได้

  • ต้องตั้งรหัสใหม่ให้เสร็จก่อน จึงเข้าหน้าอื่นได้
  • เข้าหน้าแรกแล้ว บทเรียน “เริ่มใช้งานครั้งแรก” เริ่มเอง แล้วต่อด้วยบทของ Admin (เปิดงาน)
  • กด “ข้ามทั้งหมด (Esc)” ได้ทุกเมื่อ · ปุ่มบันทึกในบทเรียนขึ้นข้อความ “โหมดฝึก · ไม่บันทึกข้อมูลจริง” และไม่บันทึกอะไรจริง
  • บางขั้นถูกข้ามไปเอง ไม่ค้าง (เช่นขั้นของหน้า “ทะเบียนลูกค้า/สัญญา” ที่ยังเป็นหน้าโครง) — ถือว่าปกติ
  • เข้าใหม่แล้วบทเรียน ไม่เด้งซ้ำ · ปุ่ม “สอนใช้งาน” เปิดเมนู “เปิดดูบทเรียนซ้ำ” ให้เลือกบทส่วนกลางและบทของ Admin ได้

A2

เมนูซ้ายและหน้าแรกตรงตำแหน่ง

รอหน้าจริง

ให้ลองทำอะไร

  1. ดูเมนูซ้าย (มือถือกด ☰ “เปิดเมนู”) แล้วจดรายการที่เห็น
  2. กดโลโก้ AGA มุมซ้ายบน

ผลที่ควรได้

  • เห็นเมนูเหล่านี้ เท่านั้น — กลุ่ม “งานประจำวัน”: สถานะทะเบียนบริการ · ลูกค้ารอเก็บสถานี · กลุ่ม “ทะเบียนและสรุป”: ทะเบียนลูกค้า/สัญญา · เปิดงานเข้าทะเบียนบริการ · สรุปงานบริการรายเดือน · Dashboard สรุปมูลค่าทั้งหมด
  • ไม่มีกลุ่ม “ดูแลระบบ” และไม่มีเมนู “ลงข้อมูลทำบริการประจำเดือน” / “กล่อง AG นอกรอบประจำเดือน”
  • หน้าแรกคือ “ทะเบียนลูกค้า/สัญญา” — ตอนนี้ยังเป็นหน้าโครง (รอหน้าจริง) ให้กดเมนู “เปิดงานเข้าทะเบียนบริการ” แทน · “ลูกค้ารอเก็บสถานี” ก็ยังเป็นหน้าโครง

A3

เปิดงานใหม่ (ลูกค้า New) ลงตาราง

กระทบข้อมูลจริง

ให้ลองทำอะไร

  1. เมนู “เปิดงานเข้าทะเบียนบริการ” → เลือก เดือนเปิดงาน ให้ตรงเดือนที่สัญญาเริ่ม → กด “เพิ่มแถว”
  2. กรอก: เลขที่สัญญา (เช่น CT26-9990001 — สมมติ) · รายชื่อ (เช่น “บริษัท ทดสอบ UAT จำกัด” — สมมติ) · ประเภทงาน = New · ผู้ขาย · สาขา (พิมพ์แล้วเลือกจากรายการ) · เริ่มสัญญา · มูลค่า 1 ปี
  3. ดูช่อง เขต / Tier / สิ้นสุด และตัวนับใต้ตาราง

ผลที่ควรได้

  • ช่อง เขต · Tier · สิ้นสุด ระบบเติมให้เอง ไม่ต้องกรอก
  • ตัวนับใต้ตารางบอก “บันทึกได้ X จาก Y แถว” · ป้ายสถานะท้ายแถวขึ้นว่าครบ หรือบอกว่าขาดอะไร

A4

ช่องที่ขาด และกติกามูลค่า / ระยะสัญญา

ให้ลองทำอะไร

  1. เว้นช่องจำเป็น (เช่น เลขที่สัญญา หรือ สาขา) แล้วดูแถว
  2. กรอกทั้ง “มูลค่า 1 ปี” และ “มูลค่า 3 ปี” ในแถวเดียวกัน
  3. กดลิงก์ “Custom…” ใต้ช่อง “มูลค่า 1 ปี” แล้วใส่จำนวนเดือน 12

ผลที่ควรได้

  • แถวที่ขาดข้อมูลมี ขอบแดง และป้ายท้ายแถวบอก เช่น “ขาด เลขที่สัญญา · สาขา”
  • กรอกมูลค่าสองช่อง → ขึ้น “กรอกมูลค่าได้ช่องเดียว (1 ปี หรือ 3 ปี)”
  • Custom ใส่ 12 → ขึ้น “ระยะสัญญา Custom ต้องเป็นจำนวนเดือน 1–35 (ไม่ใช่ 12)”

A5

บันทึกเข้าทะเบียน

กระทบข้อมูลจริง

ให้ลองทำอะไร

  1. ทำแถวให้ครบแล้วกด “บันทึกเข้าทะเบียน” (มุมขวาล่างของตาราง)
  2. ปิดแล้วเปิดหน้าเดิมใหม่ เลือกเดือนเดิม แล้วหาแถวนั้น

ผลที่ควรได้

  • ขึ้น “บันทึกเข้าทะเบียนครบ N แถว” (ถ้าบางแถวไม่ผ่านจะบอกว่า “บันทึกสำเร็จ … · ไม่สำเร็จ … แถว” และมีข้อความใต้แถว)
  • แถวที่บันทึกแล้วยังอยู่ในตารางของเดือนนั้นหลังเปิดใหม่

A6

ลูกค้าชื่อซ้ำในสาขาเดียวกัน

ให้ลองทำอะไร

  1. เปิดงานอีกสัญญา โดยใช้ ชื่อลูกค้าเดียวกัน และสาขาเดียวกับข้อก่อน แล้วกด “บันทึกเข้าทะเบียน”

ผลที่ควรได้

  • ขึ้นหน้าต่าง “พบลูกค้าชื่อนี้ในสาขาแล้ว” มี 3 ทางเลือก: “ใช้ลูกค้ารายนี้” · “เป็นคนละราย · สร้างลูกค้าใหม่” · “ยกเลิก (ยังไม่บันทึกแถวนี้)”
  • ปิดหน้าต่างโดยไม่เลือก = ไม่บันทึกแถวนั้น และมีข้อความให้กดบันทึกใหม่เพื่อเลือก

A7

ต่อสัญญา (Renew) ผูกกับสัญญาเดิม

กระทบข้อมูลจริง

ให้ลองทำอะไร

  1. เพิ่มแถวใหม่ → ประเภทงาน = Renew → กดช่อง “⚠ ยังไม่ผูก · ค้นหา”
  2. ในหน้าต่าง “ผูกลูกค้าเดิม (Renew)” พิมพ์ชื่อลูกค้าหรือเลขที่สัญญาเดิมอย่างน้อย 2 ตัวอักษร แล้วเลือกสัญญาเก่า (ใช้สัญญาที่สร้างในข้อก่อน)
  3. ลองตั้งวันเริ่มสัญญาใหม่ให้ ก่อน วันเริ่มสัญญาเก่า

ผลที่ควรได้

  • ผูกแล้ว สาขา/ชื่อลูกค้าของแถวใหม่ล็อกตามสัญญาเก่า (ไม่สร้างลูกค้าใหม่)
  • วันเริ่มใหม่ไม่หลังสัญญาเก่า → จอเตือนและบันทึกไม่ได้
  • กด ✕ ที่ช่องลูกค้าเดิม = เลิกผูก (ก่อนบันทึกเท่านั้น)
ผล
A8

แนบไฟล์ PDF สัญญา

ให้ลองทำอะไร

  1. ที่ท้ายแถว กดปุ่ม “แนบ” → หน้าต่าง “ไฟล์แนบ” → “เลือกไฟล์ PDF” (ใช้ PDF เปล่า/ตัวอย่าง ไม่ใช่สัญญาจริง ขนาดไม่เกิน 5 MB)
  2. ลองเลือกไฟล์ที่ใหญ่เกิน 5 MB (ถ้ามี)

ผลที่ควรได้

  • แนบแล้วปุ่มเปลี่ยนเป็น “PDF ✓” · มีปุ่ม “เปิดดู” และ “ลบ” (ลบจะถามยืนยันก่อน)
  • ไฟล์เกิน 5 MB → ขึ้น “PDF ต้องไม่เกิน 5 MB — …” และไม่รับไฟล์

แก้สัญญาที่บันทึกแล้ว

ให้ลองทำอะไร

  1. ใช้ช่อง “กรองในตารางนี้” หาแถวของสัญญาทดสอบ → กด “แก้” ท้ายแถว
  2. แก้ค่าที่แก้ได้ (เช่น หมายเหตุ หรือมูลค่า) แล้วกด “บันทึก” · ลองกด “ยกเลิก” อีกรอบ
  3. เอาเมาส์ชี้ (มือถือ: แตะ) ช่อง สาขา และ ชื่อลูกค้า

ผลที่ควรได้

  • ช่องกลายเป็นช่องกรอก · กด “บันทึก” ค่าเปลี่ยน · กด “ยกเลิก” ค่ากลับเป็นเดิม
  • สาขากับชื่อลูกค้าแก้ไม่ได้ และมีข้อความบอกเหตุผล (เช่น “แก้สาขาไม่ได้ — ถ้าลงผิดสาขาให้ลบสัญญานี้แล้วเปิดงานใหม่”)

ลบสัญญา

กระทบข้อมูลจริง

ให้ลองทำอะไร

  • สัญญาที่มีผลบริการแล้ว → ขึ้น “ลบไม่ได้ เพราะสัญญานี้มีผลบริการ…” (ถ้าไม่มีสัญญาแบบนี้ให้เลือก “ข้าม”)

  • เห็นครบ 3 ขั้นของส่วนกลาง · มีคำเตือนว่าปิดส่วนกลางมีผลกับทุกสาขาส่วนกลาง (24 สาขา)
